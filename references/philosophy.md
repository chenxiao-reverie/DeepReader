# philosophy.md — 哲学分析框架

> 适用：西方哲学、中国哲学、伦理学、形而上学、认识论、语言学哲学等哲学著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：命题→论证→反驳→结论 或 对话体/论辩体
- **语言**：抽象、严谨、概念密集、逻辑性强
- **篇幅**：通常 200-400 页
- **标志词**："存在""真理""正义""善""自由意志""形而上学""认识论""语法""语义"

### 常见子类型
- 西方哲学（《理想国》《存在与时间》《纯粹理性批判》）
- 中国哲学（《论语》《道德经》《庄子》）
- 伦理学（《道德情操论》《正义论》）
- 形而上学（《存在与虚无》《形而上学》）
- 认识论（《人类理解研究》《纯粹理性批判》）
- 语言哲学（《哲学研究》《词与物》）
- 政治哲学（《利维坦》《社会契约论》）

### 易混淆体裁及区分要点
- vs **宗教**：哲学纯理性思辨，宗教有信仰维度
- vs **社会科学**：哲学侧重概念分析和逻辑论证，社科侧重经验研究
- vs **文学**：哲学追求真理/智慧，文学追求审美/情感

---

## 哲学普及 vs 学术哲学区分处理

哲学著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **哲学普及** | 面向大众、语言通俗、多用案例和故事、少用专业术语 | 《苏菲的世界》《论语》《道德经》《人生的智慧》《被讨厌的勇气》 |
| **学术哲学** | 面向学者、术语密集、论证严密、引用文献 | 《存在与时间》《纯粹理性批判》《哲学研究》《正义论》 |

### 处理规则

**哲学普及（占大多数）**：
- 核心目标：让读者"获得智慧、指导生活"
- 侧重：核心问题大白话、思想实验故事化、实践应用
- 弱化：概念辨析、论证结构评估、学派源流（可提及但不深入分析）

**学术哲学（占少数）**：
- 核心目标：理解哲学体系和论证逻辑
- 保留专业分析维度（概念辨析、论证结构、学派源流）

> ⚠️ **默认按哲学普及处理**，除非明显是学术专著（术语密集、论证严密、引用文献）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按哲学普及维度执行**，学术哲学可保留"概念辨析""论证结构""学派源流"等专业维度。

### 维度一：核心问题大白话 ⭐

**分析问题**：这本书想回答什么人生问题？用大白话说清楚。

**方法指引**：
1. 提取核心哲学问题
2. 每个问题用**大白话**重新表述（如"什么是正义"→"怎样做才算公平"）
3. 标注原文依据
4. 用生活场景辅助解释

**输出格式**：

```markdown
## 核心问题（大白话版）

### 问题1：[标题]
- 大白话表述：[用日常语言重新表述]
- 原文依据：[引用原文]
- 生活场景：[什么时候会遇到这个问题？]

### 问题2：[标题]
...
```

### 维度二：思想实验故事化 ⭐

**分析问题**：作者用了哪些有趣的假设来帮助我们理解？

**方法指引**：
1. 提取核心思想实验
2. 用讲故事的方式复述（情境→冲突→选择→启示）
3. 标注原文依据
4. 评估：这个假设对普通人有什么启发？

**输出格式**：

```markdown
## 思想实验

### 实验1：[名称]
- 故事复述：[用讲故事的方式]
- 原文依据：[引用原文]
- 核心冲突：[这个实验让我们面临什么选择？]
- 对普通人的启发：[读完我学到了什么？]

### 实验2：[名称]
...
```

### 维度三：实践应用 ⭐

**分析问题**：这些哲学观点，怎么用在我的生活里？

**方法指引**：
1. 这本书能解释哪些人生困惑？
2. 能指导哪些日常决策？（职业/人际/自我认知）
3. 读完后，我看问题的角度有什么不同？
4. 有哪些可以立即尝试的"哲学练习"？

**输出格式**：

```markdown
## 实践应用

### 解释人生困惑
- [困惑1]：[书中观点如何解释]
- [困惑2]：[书中观点如何解释]

### 指导日常决策
- [决策场景1]：[书中观点如何指导]
- [决策场景2]：[书中观点如何指导]

### 哲学练习
[1-2个可以立即尝试的练习]
```

### 维度四：哲学背景（扩展）

**分析问题**：这本书在哲学传统中的位置？

**方法指引**：
1. 用大白话解释作者的哲学流派（如"儒家""存在主义""功利主义"）
2. 标注作者继承了什么、批判了什么（用大白话）

**输出格式**：

```markdown
## 哲学背景

### 作者流派
[用大白话解释作者的哲学流派]

### 思想传承
[继承了什么、批判了什么]
```

---

## 执行步骤

```
Step 1: 通读全书，提取核心哲学问题
Step 2: 用大白话重新表述每个问题
Step 3: 用讲故事的方式复述思想实验
Step 4. 关联生活，提炼实践应用
Step 5: 简述哲学背景（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个有智慧的朋友在和你聊天
- 用大白话讲清楚哲学，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这个问题其实是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "这个思想实验很有意思/有点难懂，因为……"
- "作者讲得很清楚/这里有点绕，可能是因为……"

### 禁忌用语
- 不要堆砌哲学术语而不解释
- 不要评估"论证强度""逻辑漏洞"等专业概念（除非学术哲学）
- 不要把哲学普及当成学术论文分析
- 不要忽视"这本书好不好读"这个核心问题

## 常见陷阱

1. **术语轰炸**：堆砌"形而上学""认识论"等术语 → 用大白话讲哲学
2. **学术化分析**：用评估学术论文的标准分析哲学普及 → 普通读者关心的是"对我有什么用"
3. **脱离生活**：不与实践关联 → 哲学最终要指导生活
4. **过度简化**：把复杂的哲学论证简化为一句话 → 保持论证的完整性

---

*哲学分析的关键是：在理解与批判之间找到平衡——先理解作者在说什么，再评估论证是否成立。*

## 补充维度：思维工具（核心）

**分析问题**：这本书教了我什么思考方法？

**方法指引**：
1. 苏格拉底式追问：不断地问"为什么"
2. 笛卡尔的怀疑方法：什么可以确定？
3. 康德的二律背反：两个相反的命题都可以成立
4. 罗尔斯的无知性幕：如果不知道自己在社会中的位置，会怎么选择？
5. 用大白话解释思维工具，并说明能迁移到哪些问题

**输出格式**：

```markdown
## 思维工具

### 核心思维方法
[这本书教了我什么思考方法？用大白话解释]

### 可迁移应用
[这些思维工具还能用在哪些问题？]
```
