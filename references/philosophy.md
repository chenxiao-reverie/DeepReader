# philosophy.md — 哲学分析框架

> 适用：西方哲学、中国哲学、伦理学、形而上学、认识论、语言学哲学等哲学著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：命题→论证→反驳→结论 或 对话体/论辩体
- **语言**：抽象、严谨、概念密集、逻辑性强
- **篇幅**：通常 200-400 页
- **标志词**："存在""真理""正义""善""自由意志""形而上学""认识论""语法""语义"

### 常见子类型
- 西方哲学（《理想国》《存在与时间》《纯粹理性批判》）
- 中国哲学（《论语》《道德经》《庄子》）
- 伦理学（《道德情操论》《正义论》）
- 形而上学（《存在与虚无》《形而上学》）
- 认识论（《人类理解研究》《纯粹理性批判》）
- 语言哲学（《哲学研究》《词与物》）
- 政治哲学（《利维坦》《社会契约论》）

### 易混淆体裁及区分要点
- vs **宗教**：哲学纯理性思辨，宗教有信仰维度
- vs **社会科学**：哲学侧重概念分析和逻辑论证，社科侧重经验研究
- vs **文学**：哲学追求真理/智慧，文学追求审美/情感

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：核心命题 ⭐

**分析问题**：这本书的核心哲学问题是什么？

**方法指引**：
1. 核心问题提取：作者试图回答什么哲学问题？
2. 核心主张概括：一句话说清核心哲学立场
3. 问题史定位：这个问题在哲学史中的位置
4. 当代回响：这个问题在今天仍有何意义

**输出格式**：

```markdown
## 核心命题

### 哲学问题
[作者试图回答的核心哲学问题]

### 核心主张
[一句话概括核心哲学立场]

### 问题史定位
[这个问题在哲学史中的位置]
```

### 维度二：概念辨析 ⭐

**分析问题**：关键概念如何定义和区分？

**方法指引**：
1. 核心概念提取：关键哲学术语及其定义
2. 概念区分：相似概念的区别（如"自由"vs"放纵"）
3. 概念演变：概念在哲学史中的演变
4. 概念网络：概念间的逻辑关系

**输出格式**：

```markdown
## 概念辨析

### 核心概念
| 概念 | 定义 | 与相近概念的区别 |
|------|------|------------------|
| ... | ... | ... |
```

### 维度三：论证结构 ⭐

**分析问题**：如何从前提推出结论？

> 💡 **入门级指引**：论证还原三步法——①作者的核心结论是什么？②用了哪些前提/理由来支撑？③从前提到结论的推理是否合理？普通读者不需要专业逻辑学，只需问"这个推理站得住脚吗？"

**方法指引**：
1. 论证还原：前提→推理→结论
2. 论证方法：演绎/归纳/类比/反证/归谬
3. 论证强度评估：逻辑是否严密？有无漏洞？
4. 反例处理：是否考虑了反面论证？

**输出格式**：

```markdown
## 论证结构

### 核心论证
- 前提：...
- 推理：...
- 结论：...

### 论证评估
[论证强度和可能的漏洞]
```

### 维度四：思想实验 ⭐

**分析问题**：用了哪些思想实验？

**方法指引**：
1. 思想实验提取：书中使用了哪些经典思想实验？
2. 实验功能：思想实验在论证中起什么作用？
3. 实验分析：思想实验是否有效？
4. 思想实验谱系：与其他哲学家的思想实验的关系

### 维度五：学派源流（扩展）

**分析问题**：在哲学传统中的位置？

**方法指引**：
1. 学派归属：属于哪个哲学流派？
2. 与前人关系：继承了什么、批判了什么
3. 与同时代关系：与同时代哲学家的对话
4. 对后世影响：影响了哪些后续哲学家

**输出格式**：

```markdown
## 学派源流

### 学派归属
[所属哲学流派]

### 思想谱系
- 继承了：...
- 批判了：...
- 影响了：...
```

### 维度六：文体与表达（扩展）

**分析问题**：作者如何写哲学？

**方法指引**：
1. 文体风格：对话体/论文体/格言体/书信体？
2. 语言特色：晦涩还是清晰？抽象还是具象？
3. 表达技巧：如何让抽象的哲学思想变得可感可知？
4. 写作背景：作者的个人经历如何影响其写作风格？

### 维度七：实践应用（扩展）

**分析问题**：这个哲学观点如何指导行动？

**方法指引**：
1. 生活启示：对日常生活有什么具体指导？
2. 思维工具：能用什么哲学方法分析现实问题？

## 执行步骤

```
Step 1: 通读全书，标记核心哲学问题和主张
Step 2: 梳理核心概念及其定义
Step 3: 还原核心论证结构
Step 4: 提取思想实验
Step 5: 分析学派源流和哲学史定位
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 理性、严谨、有思辨深度
- 像一个哲学教授在讲台上

### 示范句式
- "作者的核心论点是……，这一观点挑战了传统的……"
- "要理解这个论证，我们需要先澄清……这个概念。"
- "这个思想实验的精妙之处在于……"

### 禁忌用语
- 不要武断判断"对/错"
- 不要过度简化复杂的哲学论证
- 不要把哲学分析变成知识罗列

## 常见陷阱

1. **过度简化**：把复杂的哲学论证简化为一句话 → 保持论证的完整性
2. **武断判断**：武断判断哲学观点"对/错" → 客观呈现论证
3. **忽视论证**：只说结论不说论证过程 → 论证结构是核心
4. **脱离语境**：不分析哲学史背景 → 学派源流是重要维度
5. **堆砌术语**：堆砌哲学术语而不解释 → 首次出现时解释

---

*哲学分析的关键是：在理解与批判之间找到平衡——先理解作者在说什么，再评估论证是否成立。*
