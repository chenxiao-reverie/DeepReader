# history.md — 历史著作分析框架

> 适用：通史、断代史、专题史、史学理论、历史科普等历史著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：编年体（按时间顺序）或 纪事体（按事件/主题分章）
- **语言**：客观叙述、有史料引用、注重因果分析
- **篇幅**：差异大（单本到多卷本）
- **标志词**："据记载""史料显示""XX年""考古发现""史学界认为"

### 常见子类型
- 通史（《史记》《全球通史》《人类简史》）
- 断代史（《万历十五年》《巨流河》）
- 专题史（《枪炮、病菌与钢铁》《棉花帝国》）
- 史学理论（《历史研究》《元史学》）
- 历史科普（《明朝那些事儿》）

### 易混淆体裁及区分要点
- vs **传记**：历史聚焦事件/制度/时代，传记聚焦个体生命
- vs **宗教**：历史侧重客观史实和因果分析，宗教侧重信仰体系和教义诠释
- vs **神话**：历史追求事实重建，神话侧重象征和原型

## 历史科普 vs 学术史学区分处理

历史著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **历史科普** | 面向大众、叙事生动、语言通俗、少引史料原文 | 《人类简史》《万历十五年》《明朝那些事儿》《枪炮、病菌与钢铁》 |
| **学术史学** | 面向学者、史料密集、引用原文、方法论说明 | 《历史研究》《元史学》《资治通鉴》学术注本 |

### 处理规则

**历史科普（占大多数）**：
- 核心目标：让读者"看懂故事、获得启示、指导当下"
- 侧重：核心事件故事化、以史为鉴、当代关联、阅读体验
- 弱化：史料来源考据、史观流派归属、布罗代尔三时段（可提及但不深入分析）

**学术史学（占少数）**：
- 核心目标：理解史学方法和解释框架
- 保留专业分析维度（史料批判、史观分析、因果分析）

> ⚠️ **默认按历史科普处理**，除非明显是学术专著（史料密集、引用原文、方法论说明）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按历史科普维度执行**，学术史学可保留"史料批判""史观分析""因果分析"等专业维度。

### 维度一：核心事件故事化 ⭐

**分析问题**：这本书讲了什么历史故事？

**方法指引**：
1. 提取核心历史事件/节点
2. 用讲故事的方式串联（时间、地点、人物、冲突、结果）
3. 标注原文中最生动的叙述
4. 评估：这个故事讲得好不好？

**输出格式**：

```markdown
## 核心事件

### 事件1：[标题]
- 时间/地点：
- 关键人物：
- 冲突与转折：
- 结果与影响：
- 原文精华：[引用最生动的叙述]

### 事件2：[标题]
...
```

### 维度二：以史为鉴 ⭐

**分析问题**：这段历史对今天的我有什么启示？

**方法指引**：
1. 这本书能解释哪些当下面临的问题？
2. 能指导哪些个人/职业/社会决策？
3. 读完后，我看问题的角度有什么不同？
4. 有哪些"历史重演"的风险？

**输出格式**：

```markdown
## 以史为鉴

### 对个人的启示
- [启示1]：[历史事件如何指导个人决策]
- [启示2]：[历史事件如何指导个人决策]

### 对社会的启示
- [现象1]：[历史如何映射当下]
- [现象2]：[历史如何映射当下]

### 历史教训
[最应该记住的1-2条教训]
```

### 维度三：关键人物 ⭐

**分析问题**：谁是推动历史的关键人物？他们做了什么选择？

**方法指引**：
1. 提取 关键人物
2. 每人用"姓名+身份+关键选择+历史影响"概括
3. 标注原文依据
4. 评估：这个人物的选择对普通人有什么启发？

**输出格式**：

```markdown
## 关键人物

### 人物1：[姓名]
- 身份：
- 关键选择：
- 历史影响：
- 原文依据：
- 对普通人的启发：

### 人物2：[姓名]
...
```

### 维度四：阅读体验评估 ⭐

**分析问题**：这本书讲得好不好读？

**方法指引**：
1. 叙事结构：按时间/按主题/按人物？清晰吗？
2. 语言风格：学术严谨型还是通俗故事型？
3. 写作亮点：最出色的写作手法
4. 阅读难度：是否容易卡住？

**输出格式**：

```markdown
## 阅读体验

### 叙事结构
[按时间/按主题/按人物，是否清晰]

### 语言风格
[学术严谨型/通俗故事型，是否好读]

### 写作亮点
[最出色的1-2个写作手法]

### 阅读难度
[容易/适中/偏难，哪些地方容易卡住]
```

### 维度五：史观视角（扩展）

**分析问题**：作者用什么视角解释历史？

**方法指引**：
1. 用大白话解释作者的史观（如"关注经济基础""关注文化碰撞""关注跨地域联系"）
2. 标注作者的立场和预设立场
3. 用大白话呈现不同解释（如有）

**输出格式**：

```markdown
## 史观视角

### 作者视角
[用大白话解释作者的史观]

### 立场偏向
[作者的预设立场]

### 不同解释
[如有，用大白话呈现]
```

## 执行步骤

```
Step 1: 通读全书，提取核心历史事件
Step 2: 用讲故事的方式串联事件，评估叙事质量
Step 3: 找出关键人物及其选择
Step 4: 关联当下，提炼以史为鉴的启示
Step 5: 评估阅读体验（结构、风格、难度）
Step 6: 简述史观视角（扩展）
Step 7: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个会讲故事的朋友在和你聊天
- 用大白话讲清楚历史，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "这段历史的大意是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "作者讲得很精彩/这里有点难读，可能是因为……"
- "这段历史让我想到今天……"

### 禁忌用语
- 不要堆砌学术术语而不解释
- 不要评估"史料可信度""史观流派"等专业概念（除非学术史学）
- 不要把历史科普当成学术论文分析
- 不要忽视"这个故事讲得好不好"这个核心问题

## 常见陷阱

1. **术语轰炸**：堆砌"史料考据""史观流派"等术语 → 用大白话讲故事
2. **学术化分析**：用评估学术论文的标准分析历史科普 → 普通读者关心的是"故事讲得好不好、对我有什么用"
3. **忽视阅读体验**：只分析内容不评价"好不好读" → 阅读体验是核心维度
4. **脱离当下**：不与当代关联 → 以史为鉴是读者最关心的
5. **以今度古**：用今天的标准评判历史人物 → 回到历史情境

---

*历史分析的关键是：在事实与解释之间找到平衡——既尊重史料的客观性，又理解解释的多元性。*
