# business.md — 商业/财经分析框架

> 适用：商业模式、战略管理、市场营销、组织行为、领导力、投资等商业财经著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→框架→案例→行动建议
- **语言**：实用导向、多用商业术语和案例
- **篇幅**：通常 200-350 页
- **标志词**："商业模式""战略""竞争优势""价值链""领导力""投资""复利"

### 常见子类型
- 战略管理（《竞争战略》《基业长青》）
- 商业模式（《商业模式新生代》《价值主张设计》）
- 市场营销（《定位》《影响力》）
- 组织行为/领导力（《从优秀到卓越》《第五项修炼》）
- 创业/创新（《精益创业》《创新者的窘境》）
- 财务管理/投资（《聪明的投资者》《穷查理宝典》）
- 经济学（《国富论》《21世纪资本论》）

### 易混淆体裁及区分要点
- vs **成长实用类**：商业侧重组织/市场/竞争，成长侧重个人效能
- vs **社科**：商业侧重实践应用，社科侧重理论解释
- vs **经济**：商业侧重企业/管理层面，经济侧重宏观/市场层面

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：核心框架/模型 ⭐

**分析问题**：这本书的核心商业框架是什么？

**方法指引**：
1. 核心模型提取：作者提出了什么分析框架？
2. 模型结构：框架的构成要素和关系
3. 模型应用：如何用这个框架分析商业问题？
4. 模型评价：解释力强弱、适用范围

**输出格式**：

```markdown
## 核心框架

### 核心模型
[作者提出的分析框架]

### 模型结构
[框架的构成要素和关系]

### 应用场景
[如何使用这个框架]
```

### 维度二：关键洞察 ⭐

**分析问题**：最有价值的商业洞察是什么？

**方法指引**：
1. 反常识发现：哪些观点颠覆了传统认知？
2. 趋势判断：对行业/市场趋势的判断
3. 失败教训：从失败案例中学到了什么？
4. 成功要素：成功的关键因素是什么？

### 维度三：案例分析 ⭐

**分析问题**：用了哪些案例支撑论点？

**方法指引**：
1. 案例提取：书中引用了哪些商业案例？
2. 案例功能：每个案例在论证中起什么作用？
3. 案例评价：案例是否典型、是否有说服力？
4. 案例迁移：这些案例对今天还有参考价值吗？

**输出格式**：

```markdown
## 案例分析

### 核心案例
| 案例 | 行业 | 论证功能 | 当代参考价值 |
|------|------|----------|-------------|
| ... | ... | ... | ★★★★☆ |
```

### 维度四：实操工具 ⭐

**分析问题**：读完能用什么工具？

**方法指引**：
1. 分析工具：SWOT/波特五力/商业模式画布/价值链分析……
2. 决策工具：如何用这个框架做商业决策？
3. 行动清单：读完可以采取什么行动？
4. 适用边界：什么情况下适用/不适用？

### 维度五：行业洞察（扩展）

**分析问题**：对行业的理解？

**方法指引**：
1. 行业分析：对特定行业的深度理解
2. 竞争格局：行业竞争态势的分析
3. 趋势预判：对行业未来趋势的判断
4. 颠覆创新：可能的颠覆性变化

### 维度六：投资视角（如适用，扩展）

**分析问题**：对投资的启示？

**方法指引**：
1. 价值评估：如何评估企业/资产价值？
2. 风险管理：如何管理投资风险？
3. 市场心理：市场参与者的心理分析
4. 长期主义：复利思维和长期投资

### 维度七：写作手法（扩展）

**分析问题**：作者如何把商业写得引人入胜？

**方法指引**：
1. 叙事结构：如何组织内容？案例驱动还是理论驱动？
2. 语言风格：学术严谨型还是通俗易懂型？
3. 说服技巧：如何让读者信服？
4. 写作特色：与其他商业书籍相比有何独特之处？

## 执行步骤

```
Step 1: 通读全书，标记核心框架和模型
Step 2: 梳理关键洞察和反常识发现
Step 3: 分析案例及其论证功能
Step 4: 提取实操工具
Step 5: 分析行业洞察和趋势判断
Step 6: 分析投资视角（如适用）
Step 7: 进行批判反思
Step 8: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 务实、专业、有商业敏感度
- 像一个资深商业顾问

### 示范句式
- "这个框架的核心价值在于……"
- "从商业角度来看，这一洞察的关键在于……"
- "值得注意的是，这个结论在……条件下可能不成立。"

### 禁忌用语
- 不要空泛地说"这本书很有价值"
- 不要忽视框架的适用边界
- 不要把商业分析变成成功学鸡汤

## 常见陷阱

1. **成功学化**：把商业分析变成"成功秘诀" → 保持分析的客观性
2. **忽视边界**：不分析框架的适用条件 → 适用边界是重要维度
3. **案例堆砌**：只列案例不分析 → 案例功能分析是核心
4. **时代忽视**：不考虑出版时的时代背景 → 时代局限是重要维度
5. **术语堆砌**：堆砌商业术语而不解释 → 首次出现时解释

---

*商业分析的关键是：在理论与实践之间找到平衡——既要有框架的深度，又要有实操的价值。*
