# business.md — 商业/财经分析框架

> 适用：商业模式、战略管理、市场营销、组织行为、领导力、投资等商业财经著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→框架→案例→行动建议
- **语言**：实用导向、多用商业术语和案例
- **篇幅**：通常 200-350 页
- **标志词**："商业模式""战略""竞争优势""价值链""领导力""投资""复利"

### 常见子类型
- 战略管理（《竞争战略》《基业长青》）
- 商业模式（《商业模式新生代》《价值主张设计》）
- 市场营销（《定位》《影响力》）
- 组织行为/领导力（《从优秀到卓越》《第五项修炼》）
- 创业/创新（《精益创业》《创新者的窘境》）
- 财务管理/投资（《聪明的投资者》《穷查理宝典》）
- 经济学（《国富论》《21世纪资本论》）

### 易混淆体裁及区分要点
- vs **成长实用类**：商业侧重组织/市场/竞争，成长侧重个人效能
- vs **社科**：商业侧重实践应用，社科侧重理论解释
- vs **经济**：商业侧重企业/管理层面，经济侧重宏观/市场层面

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：核心观点大白话 ⭐

**分析问题**：这本书最核心的商业观点是什么？用大白话说清楚。

**方法指引**：
1. 提取核心商业观点
2. 每个观点用大白话解释
3. 标注原文依据
4. 用生活案例辅助解释

**输出格式**：

```markdown
## 核心观点（大白话版）

### 观点1：[标题]
- 大白话解释：[用日常语言讲清楚]
- 原文依据：[引用原文]
- 生活案例：[用生活中的例子辅助理解]

### 观点2：[标题]
...
```

### 维度二：关键洞察 ⭐

**分析问题**：最有价值的商业洞察是什么？

**方法指引**：
1. 反常识发现：哪些观点颠覆了传统认知？
2. 成功/失败教训：从案例中学到了什么？
3. 用大白话表达

### 维度三：作者可信度 ⭐

**分析问题**：作者有没有资格讲这个？

**方法指引**：
1. 作者背景：作者是实战派还是咨询派？有没有成功案例？
2. 框架适用边界：这个框架什么时候好用、什么时候会失效？
3. 案例质量：这些案例是不是精心挑选的？有没有"报喜不报忧"？

**输出格式**：

```markdown
## 作者可信度

### 作者背景
[作者是实战派还是咨询派？有没有成功案例？]

### 框架适用边界
[这个框架什么时候好用、什么时候会失效？]

### 案例质量
[这些案例是不是精心挑选的？]
```

### 维度四：对我的启示与应用 ⭐

**分析问题**：这些商业观点，如何改变我的认知和行动？

**方法指引**：
1. 这本书能解释哪些日常商业现象/困惑？（消费/职场/创业）
2. 能指导哪些日常决策？（购物/职业/投资）
3. 读完后，我看商业世界的角度有什么不同？
4. 有哪些可以立即尝试的"行动清单"？

**输出格式**：

```markdown
## 对我的启示与应用

### 解释日常现象/困惑
- [现象1]：[书中观点如何解释]
- [现象2]：[书中观点如何解释]

### 指导日常决策
- [决策场景1]：[书中观点如何指导]
- [决策场景2]：[书中观点如何指导]

### 认知升级
[读完后，我对XX的理解从___变成了___]

### 行动清单
[若干条可以立即尝试的行动]
```

### 维度五：行业洞察（扩展）

**分析问题**：对行业的理解？

**方法指引**：
1. 行业分析：对特定行业的深度理解
2. 竞争格局：行业竞争态势的分析
3. 趋势预判：对行业未来趋势的判断

### 维度六：投资视角（扩展，如适用）

**分析问题**：对投资的启示？

**方法指引**：
1. 价值评估：如何评估企业/资产价值？
2. 风险管理：如何管理投资风险？
3. 市场心理：市场参与者的心理分析

## 执行步骤

```
Step 1: 通读全书，提取核心商业观点
Step 2: 用大白话解释每个观点
Step 3: 找出关键洞察
Step 4: 关联日常现象和决策场景，提炼对我的启示与应用
Step 6: 简述行业洞察和投资视角（扩展）
Step 7: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个务实的朋友在和你聊天
- 用大白话讲清楚商业，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这本书的核心意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "这个观点可以用在……"

### 禁忌用语
- 不要堆砌"商业模式""价值链"等术语
- 不要空泛地说"这本书很有价值"
- 不要把商业分析变成成功学鸡汤
- 不要忽视作者是否有资格讲这个

## 常见陷阱

1. **术语轰炸**：堆砌"商业模式""价值链"等术语 → 用大白话讲商业
2. **成功学化**：把商业分析变成"成功秘诀" → 保持分析的客观性
3. **与我无关**：不联系自身 → 商业书的最终价值是启发自己
4. **作者盲信**：不评估作者背景 → 作者有没有资格讲这个？
4. **忽视边界**：不分析框架的适用条件 → 适用边界是重要维度

---

*商业分析的关键是：在理论与实践之间找到平衡——既要有框架的深度，又要有实操的价值。*
