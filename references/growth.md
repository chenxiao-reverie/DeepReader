# growth.md — 个人成长/实用类分析框架

> 适用：自我提升、习惯养成、效率方法、思维训练、职场发展、学习方法论等非虚构实用书籍。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：章节体，每章围绕一个核心观点/方法展开
- **语言**：通俗易懂、多用类比和案例、直接面向读者说话
- **篇幅**：通常 150-300 页，8-15 章
- **标志词**："如何""方法""步骤""习惯""思维模型""效率""提升"

### 常见子类型
- 习惯养成类（《原子习惯》《掌控习惯》）
- 思维方法类（《思考，快与慢》《穷查理宝典》）
- 职场发展类（《深度工作》《原则》）
- 学习方法论类（《认知天性》《如何高效学习》）
- 情绪管理类（《非暴力沟通》《被讨厌的勇气》）

### 易混淆体裁及区分要点
- vs **心理学**：成长类侧重"怎么做"（行动导向），心理学侧重大脑/行为机制（理论导向）
- vs **传记**：成长类以"观点+方法"为骨架，传记以"人生经历"为骨架
- vs **技能学习**：成长类侧重"认知/习惯转变"，技能类侧重"学会做一件事"。若书籍同时涉及两者（如学习方法论），按 `_shared.md` 的"特殊情形"规则让用户选择

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

本体裁采用 **线性流程**，从"理解书"到"变成行动"形成闭环。

### 维度一：书籍定位与背景扫描 ⭐

**分析问题**：这本书"对我的成长有啥用"？

**执行动作**：
- 书籍类型与成长领域锚定
- 作者背景与成长价值关联
- 核心价值与成长收益量化
- 精准读者定位

### 维度二：萃取目标与问题锚定 ⭐

**分析问题**：一本书的价值，在于解决真实的成长困惑。

**执行动作**：
- 根本问题场景化
- 核心观点与成长结果绑定
- 痛点与成长代价明确
- 反常识观点与成长影响

### 维度三：核心知识单元萃取 ⭐

**分析问题**：把书中的核心知识拆成"小模块"，每个模块都要"能看懂、能用上"。

**执行动作**：每个知识单元需包含：

| 元素 | 说明 |
|------|------|
| 核心内容 | 一句话精准概括 |
| 书籍依据 | 引用原文或精炼概括（注明章节/页码） |
| 成长卡点适配 | 能解决的具体成长卡点 |
| 价值意义与场景应用 | 职场/学习/生活场景 + 微案例 |

**提醒**：易踩坑的使用误区

### 维度四：深度逻辑剖析 ⭐

**分析问题**：不仅要知道"方法"，还要搞懂"为什么"。

**执行动作**：
- 关键问题与解决方案拆解
- 深层逻辑与通俗转化（连续追问2-3个"为什么"，用通俗类比）
- 成长反例警示

### 维度五：场景化应用迁移 ⭐

**分析问题**：把书中的知识和自己的成长绑在一起，才算真正"学到手"。

**执行动作**：
- 陪你聊体验（先示范）
- 成长目标挂钩应用
- 优先级提醒

### 维度六：行动转化 ⭐

**分析问题**：知识不落地就是"空话"，这一步帮你把它变成可执行的行动。

**执行动作**：
- 量化行动清单（3-5条，每条明确时间限制+具体内容+完成标志）
- 预判阻碍与应对

### 维度七：辨识关键反常识 ⭐

**分析问题**：反常识的观点往往是成长的"突破口"，重点在于如何落地。

**执行动作**：每个反常识观点需补充：
1. 认知调整：用一句话说服自己接受
2. 小步尝试：今天可做的1个小改变
3. 反馈优化：判断改变是否有效的标准
4. 惯性对抗方法

### 维度八：金句萃取（扩展）

**分析问题**：金句是书籍的"能量包"，不仅要记下来，更要会用。

**执行动作**：提取**不少于10条原文金句**，每条补充：

| 元素 | 说明 |
|------|------|
| 解读 | 接地气解释成长内涵 |
| 成长场景标注 | 可用于的具体成长场景 |
| 成长口号改造 | 转化为可直接用的成长行动口号 |

### 维度九：成长资源延伸（扩展）

**分析问题**：一本书的结束，是成长的新开始。

**执行动作**：
- 推荐关联资源（同领域书籍、实用工具、优质课程）
- 成长社群互动话题（1-2个）
- 后续解读预告

### 维度十：终极凝结 ⭐

**分析问题**：用一句话总结全书最核心、最值得你刻在脑子里的结论。

**执行动作**：这句话要同时包含"核心观点"和"成长价值"。

## 语气风格规范


### 句式特征
- 通俗接地气，避免晦涩理论
- 每一步以"提示"开头（给出这一步的核心提醒）

### 示范句式
- "提示：先搞懂这本书'对你的成长有啥用'，避免盲目萃取。"
- "提醒：这个地方容易踩坑，咱们得多留个心眼。"

### 禁忌用语
- 不要居高临下的"你应该"
- 不要空泛的"这本书很有价值"
- 不要脱离原文的主观臆断

## 常见陷阱

1. **空泛化**：只说"这本书很有用"而不给出具体怎么用 → 每个知识单元必须有场景应用
2. **堆砌化**：把书中所有观点都列出来 → 聚焦核心，宁可少而精
3. **脱离原文**：用自己对主题的理解替代书中观点 → 必须有书籍依据
4. **行动缺失**：只分析知识不转化行动 → 维度六必须有可量化行动清单
5. **风格漂移**： 保持对话式语气
