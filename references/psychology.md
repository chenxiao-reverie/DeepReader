# psychology.md — 心理学分析框架

> 适用：认知心理学、发展心理学、社会心理学、临床心理学、积极心理学等心理学著作/科普作品。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→理论→实验→应用 或 现象→机制→干预
- **语言**：学术性与可读性并重，常引用经典实验
- **篇幅**：通常 200-350 页
- **标志词**："实验表明""认知""情绪""行为""大脑""心理健康""干预"

### 常见子类型
- 认知心理学（《思考，快与慢》《影响力》）
- 发展心理学（《童年与社会》《终身成长》）
- 社会心理学（《乌合之众》《社会性动物》）
- 积极心理学（《心流》《活出最乐观的自己》）
- 临床/咨询心理学（《也许你该找个人聊聊》）
- 心理学科普（《怪诞心理学》）

### 易混淆体裁及区分要点
- vs **成长实用类**：心理学侧重"大脑/行为机制"（是什么/为什么），成长类侧重"怎么做"（行动导向）
- vs **自然科学**：心理学研究对象是人的心理和行为，方法更多样
- vs **社会科学**：心理学侧重个体层面，社会科学侧重群体/制度层面

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：核心概念大白话 ⭐

**分析问题**：这本书解释了什么心理现象？用大白话说清楚。

**方法指引**：
1. 提取核心心理概念
2. 每个概念用大白话解释
3. 用生活场景/例子辅助理解
4. 标注原文依据

**输出格式**：

```markdown
## 核心概念（大白话版）

### 概念1：[名称]
- 大白话解释：[用日常语言讲清楚]
- 生活例子：[什么时候会遇到这个现象？]
- 原文依据：[引用原文]

### 概念2：[名称]
...
```

### 维度二：认知刷新点 ⭐

**分析问题**：这本书如何颠覆或刷新了我们对自己/他人的理解？

**方法指引**：
1. 找出"反直觉"或"意想不到"的心理洞察
2. 每个发现用"原来我以为……现在知道了……"的格式表达
3. 标注原文依据
4. 评估：这个刷新是"有趣但不重要"还是"改变认知"

**输出格式**：

```markdown
## 认知刷新

### 刷新点1：[标题]
- 原来我以为：[常见误解]
- 现在知道了：[心理洞察]
- 原文依据：[引用原文]
- 重要性：★★★（改变认知/有趣但不重要）
```

### 维度三：自我觉察 ⭐

**分析问题**：让我对自己有什么新认识？

**方法指引**：
1. 自我认知工具：读者可获得的自我理解
2. 反思练习：可以做什么自我反思？
3. 行为洞察：对自己行为的新解释
4. 成长启发：如何促进自我成长？

### 维度四：应用转化 ⭐

**分析问题**：如何用于自我理解/改变？

**方法指引**：
1. 自助策略：读者可以怎么用？
2. 日常应用：工作/学习/关系中的应用
3. 适用边界：什么情况下适用/不适用？

### 维度五：心理健康关联 ⭐

**分析问题**：与心理健康的关联？

**方法指引**：
1. 心理健康关联：与抑郁/焦虑/幸福感等的关联
2. 何时需要专业帮助：什么情况下应寻求专业帮助
3. 自助vs专业：哪些可以自己处理、哪些需要专业干预

### 维度六：理论脉络（扩展，学术研究适用）

**分析问题**：在心理学传统中的位置？

**方法指引**：
1. 用大白话解释作者的心理学流派
2. 简述理论对比（如有）

### 维度七：实证基础（扩展，学术研究适用）

**分析问题**：研究靠谱吗？

**方法指引**：
1. 用大白话简述经典实验
2. 这个实验是在多少人身上做的？
3. 结论被后续研究支持了吗？

### 维度八：叙事与表达（扩展）

**分析问题**：作者如何把心理学写得引人入胜？

**方法指引**：
1. 叙事结构：如何组织内容？案例驱动还是理论驱动？
2. 语言风格：学术严谨型还是通俗故事型？
3. 案例质量：案例是否生动、有代表性？
4. 表达技巧：如何让复杂的心理学概念变得易懂？

## 执行步骤

```
Step 1: 通读全书，提取核心概念
Step 2: 用大白话解释每个概念，配合生活例子
Step 3: 找出认知刷新点，用"原来我以为……现在知道了……"表达
Step 4: 设计自我觉察工具和反思练习
Step 5: 分析应用转化，评估适用边界
Step 6: 简述理论脉络和实证基础（扩展）
Step 7: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个温暖的朋友在和你聊天
- 用大白话讲清楚心理学，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这个心理现象的意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "如果你发现自己有类似的情况，可以尝试……"
- "但需要注意的是，如果症状持续，建议寻求专业帮助"

### 禁忌用语
- 不要进行诊断性表述（"你有XX症"）
- 不要堆砌"操作性定义""效应量"等术语
- 不要过度简化复杂的心理现象
- 不要替代专业心理咨询建议
- 不要把西方心理学结论当成"全人类都这样"——注意文化差异

## 常见陷阱

1. **诊断化**：对读者进行诊断性表述 → 避免"你有XX症"
2. **术语轰炸**：堆砌"操作性定义""效应量"等术语 → 用大白话讲心理学
3. **学术化分析**：用评估学术论文的标准分析心理科普 → 普通读者关心的是"对我有什么用"
4. **忽视文化**：把西方心理学结论当成普遍真理 → 分析文化差异
5. **替代专业**：用自助建议替代专业帮助 → 明确何时需要专业帮助

---

*心理学分析的关键是：科学严谨与人文关怀并重——既要有证据支撑，又要让读者感到被理解和支持。*
