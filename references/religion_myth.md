# religion_myth.md — 宗教/神话分析框架

> 适用：佛教、道教、基督教、伊斯兰教等宗教经典，以及希腊/北欧/中国/印度等神话著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：经文/章节体（宗教）或 故事集/体系化编排（神话）
- **语言**：庄重、有神圣感、充满象征
- **篇幅**：差异大（单篇经文到多卷本经典）
- **标志词**："如是我闻""经云""上帝""佛说""创世""神祇""英雄"

### 常见子类型
- 佛教经典（《心经》《金刚经》《法华经》）
- 道教经典（《道德经》《庄子》《南华经》）
- 基督教经典（《圣经》《神学大全》）
- 伊斯兰教经典（《古兰经》《圣训》）
- 希腊/罗马神话（《荷马史诗》《神谱》）
- 北欧神话（《埃达》《萨迦》）
- 中国神话（《山海经》《封神演义》部分）
- 印度神话（《摩诃婆罗多》《罗摩衍那》）
- 神话学理论（《千面英雄》《神话学导论》）

### 易混淆体裁及区分要点
- vs **哲学**：宗教有信仰维度（神圣/超越），哲学纯理性思辨
- vs **历史**：宗教/神话追求信仰/象征意义，历史追求事实重建
- vs **文学**：宗教经典有神圣性，神话是文化叙事传统

---

## 普及读物 vs 学术研究区分处理

宗教/神话著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **普及读物** | 面向大众、叙事生动、语言通俗、重故事和启发 | 《圣经故事》《希腊神话故事》《金刚经讲记》《山海经》 |
| **学术研究** | 面向学者、术语密集、引用原文、方法论说明 | 《神学大全》《神话学导论》《宗教学导论》 |

### 处理规则

**普及读物（占大多数）**：
- 核心目标：让读者"理解故事、获得启发"
- 侧重：核心故事/教义大白话、文化语境、对我的启示
- 弱化：教义源流、原型分析、母题分析（可提及但不深入分析）

**学术研究（占少数）**：
- 核心目标：理解宗教学/神话学方法
- 保留专业分析维度（教义源流、原型分析）

> ⚠️ **默认按普及读物处理**，除非明显是学术专著（术语密集、引用原文、方法论说明）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按普及读物维度执行**，学术研究可保留"教义源流""原型分析"等专业维度。

### 维度一：核心故事/教义大白话 ⭐

**分析问题**：这本书讲了什么故事或教义？用大白话说清楚。

**方法指引**：
1. 提取核心故事/教义
2. 用大白话复述（让人能听懂）
3. 标注原文依据
4. 用生活场景辅助解释

**输出格式**：

```markdown
## 核心故事/教义（大白话版）

### 故事/教义1：[标题]
- 大白话复述：[用日常语言讲清楚]
- 原文依据：[引用原文]
- 生活场景：[什么时候会遇到类似的问题？]

### 故事/教义2：[标题]
...
```

### 维度二：文化语境 ⭐

**分析问题**：在什么文化背景下产生？

**方法指引**：
1. 用大白话简述文化背景
2. 标注对今天的影响

### 维度三：对我的启示 ⭐

**分析问题**：这些故事/教义对今天的我有什么启发？

**方法指引**：
1. 这本书能解释哪些人生困惑？
2. 能指导哪些日常决策？
3. 读完后，我看问题的角度有什么不同？
4. 有哪些可以立即尝试的"生活智慧"？

**输出格式**：

```markdown
## 对我的启示

### 解释人生困惑
- [困惑1]：[书中内容如何解释]
- [困惑2]：[书中内容如何解释]

### 指导日常决策
- [决策场景1]：[书中内容如何指导]
- [决策场景2]：[书中内容如何指导]

### 生活智慧
[若干条可以立即尝试的智慧]
```

### 维度四：教义体系 ⭐（宗教适用）

**分析问题**：核心教义是什么？

**方法指引**：
1. 用大白话提取核心教义
2. 标注原文依据
3. 简述修行/实践方式

### 维度五：神祇体系 ⭐（神话适用）

**分析问题**：有哪些神祇？关系如何？

**方法指引**：
1. 用大白话简述核心神祇及其职能
2. 标注神祇关系（亲属/敌对/合作）

### 维度六：教义源流（扩展，学术研究适用）

**分析问题**：教义如何起源和发展？

**方法指引**：
1. 经典诠释：核心经文如何诠释？
2. 历史源流：何时何地由谁创立？

### 维度七：原型分析（扩展，学术研究适用）

**分析问题**：深层心理结构？

**方法指引**：
1. 荣格原型：阴影/阿尼玛/智慧老人/自性……
2. 英雄之旅：启程→启蒙→归来
3. 象征解读：核心象征的意义

```

Step 4: 提炼对我的启示
Step 5: 简述教义源流和原型分析（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 尊重信仰、学术中立
- 像一个有见识的朋友在和你聊天
- 用大白话讲清楚，尊重不同传统

### 示范句式
- "用大白话来说，这个故事/教义的意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "不同传统对这个问题的看法不同……"

### 禁忌用语
- 不要对宗教信仰做价值判断（"对/错""真/假"）
- 不要过度简化复杂的教义体系
- 不要混淆不同宗教/宗派
- 不要把神话当成"迷信"贬低

## 常见陷阱

1. **价值判断**：评判宗教"对/错" → 学术中立
2. **过度简化**：把复杂的教义体系简化为一句话 → 保持深度
3. **混淆宗教**：混淆不同宗教/宗派 → 注意区分
4. **迷信化**：把神话当成"迷信"贬低 → 理解其文化功能
5. **与我无关**：不联系自身 → 宗教/神话的最终价值是启发自己

---

*宗教/神话分析的关键是：学术中立与信仰尊重并存——既保持分析的客观性，又对信仰者的精神世界保持敬意。*

**分析问题**：神话/宗教中的人物关系如何？

**方法指引**：
1. 用大白话梳理主要人物的关系（亲属/敌对/合作）
2. 绘制简易关系图或时间线

**输出格式**：

```markdown

[主要事件的先后顺序]
```

**输出格式**：
