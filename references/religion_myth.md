# religion_myth.md — 宗教/神话分析框架

> 适用：佛教、道教、基督教、伊斯兰教等宗教经典，以及希腊/北欧/中国/印度等神话著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：经文/章节体（宗教）或 故事集/体系化编排（神话）
- **语言**：庄重、有神圣感、充满象征
- **篇幅**：差异大（单篇经文到多卷本经典）
- **标志词**："如是我闻""经云""上帝""佛说""创世""神祇""英雄"

### 常见子类型
- 佛教经典（《心经》《金刚经》《法华经》）
- 道教经典（《道德经》《庄子》《南华经》）
- 基督教经典（《圣经》《神学大全》）
- 伊斯兰教经典（《古兰经》《圣训》）
- 希腊/罗马神话（《荷马史诗》《神谱》）
- 北欧神话（《埃达》《萨迦》）
- 中国神话（《山海经》《封神演义》部分）
- 印度神话（《摩诃婆罗多》《罗摩衍那》）
- 神话学理论（《千面英雄》《神话学导论》）

### 易混淆体裁及区分要点
- vs **哲学**：宗教有信仰维度（神圣/超越），哲学纯理性思辨
- vs **历史**：宗教/神话追求信仰/象征意义，历史追求事实重建
- vs **文学**：宗教经典有神圣性，神话是文化叙事传统

## 分析维度

> 📌 **基础→进阶→拓展分级**：标注 ⭐ 为基础维度（精读必做），⭐⭐ 为进阶维度（建议做），⭐⭐⭐ 为拓展维度（深度分析时补充）。

本体裁根据宗教/神话选择不同分析维度。

### 通用维度（宗教+神话适用）

#### 维度一：叙事结构 ⭐

**分析问题**：核心故事/教义如何组织？

**方法指引**：
1. 核心故事/教义提取
2. 叙事结构：故事如何组织？
3. 母题分析：包含哪些经典母题？
4. 叙事功能：故事/教义的功能是什么？

**输出格式**：

```markdown
## 叙事结构

### 核心故事/教义
[核心内容]

### 母题分析
[包含的经典母题]

### 叙事功能
[故事/教义的功能]
```

#### 维度二：文化语境 ⭐

**分析问题**：在什么文化背景下产生？

**方法指引**：
1. 文化土壤：什么文化背景孕育了这些内容？
2. 历史演变：如何随时间变化？
3. 地域传播：如何传播到不同地区？
4. 当代回响：对今天的影响

### 宗教专用维度

#### 维度三：教义体系 ⭐

**分析问题**：核心教义是什么？

**方法指引**：
1. 核心教义提取：最根本的信仰主张
2. 神学结构：教义间的逻辑关系
3. 修行/实践体系：如何实践信仰？
4. 教义对比：与其他宗教的异同

**输出格式**：

```markdown
## 教义体系

### 核心教义
[最根本的信仰主张]

### 神学结构
[教义间的逻辑关系]

### 修行实践
[如何实践信仰]
```

#### 维度四：教义源流（扩展）

**分析问题**：教义如何起源和发展？

**方法指引**：
1. 经典诠释：核心经文如何诠释？有哪些诠释分歧？
2. 历史源流：何时何地由谁创立？宗派分化？

### 神话专用维度

#### 维度五：神祇体系 ⭐

**分析问题**：有哪些神祇？关系如何？

**方法指引**：
1. 神祇列表：主要神祇及其职能
2. 神祇关系：亲属/敌对/合作关系
3. 神祇象征：每个神祇的象征意义
4. 神祇演变：神祇形象的历史演变

**输出格式**：

```markdown
## 神祇体系

### 核心神祇
| 神祇 | 职能 | 象征 | 关系 |
|------|------|------|------|
| ... | ... | ... | ... |
```

#### 维度六：原型分析（扩展）

**分析问题**：深层心理结构？

**方法指引**：
1. 荣格原型：阴影/阿尼玛/智慧老人/自性……
2. 英雄之旅：启程→启蒙→归来
3. 象征解读：核心象征的意义

## 语气风格规范

### 称呼方式
- 尊重信仰、学术中立
- 对不同的宗教传统保持平等尊重

### 示范句式
- "从……的信仰体系来看，这一教义的核心在于……"
- "这个神话母题在世界各地都有变体……"
- "值得注意的是，不同宗派对这一经文的诠释存在差异。"

### 禁忌用语
- 不要对宗教信仰做价值判断（"对/错""真/假"）
- 不要过度简化复杂的教义体系
- 不要混淆不同宗教/宗派
- 不要把神话当成"迷信"贬低

## 常见陷阱

1. **价值判断**：评判宗教"对/错" → 学术中立
2. **过度简化**：把复杂的教义体系简化为一句话 → 保持深度
3. **混淆宗教**：混淆不同宗教/宗派 → 注意区分
4. **迷信化**：把神话当成"迷信"贬低 → 理解其文化功能
5. **西方中心**：只用西方理论解释所有宗教/神话 → 注意文化特异性
