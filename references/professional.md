# professional.md — 专业参考分析框架

> 适用：法律、医学、教育、学术论文、百科/工具书等专业著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：体系化编排，有专业术语和严谨逻辑
- **语言**：专业、精确、客观
- **篇幅**：差异极大（单篇论文到多卷本百科全书）
- **标志词**："法条""诊断""教学法""摘要""条目""检索"

### 常见子类型
- 法律（《法治及其本土资源》《法理学》《民法典解读》）
- 医学（《哈里森内科学》《人体简史》《众病之王》）
- 教育（《民主主义与教育》《教育哲学导论》）
- 学术论文（自然科学/社会科学/人文学科的论文）
- 百科/工具书（《中国大百科全书》《现代汉语词典》）
- 研究报告（智库报告/行业报告）

### 易混淆体裁及区分要点
- vs **科学**：法律/医学/教育是应用科学，有专业实践维度
- vs **社科**：法律/医学有独特的专业推理方法
- vs **百科**：百科是"查"不是"读"，但分析维度有交叉 |

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **专业阅读心法**：非专业读者阅读专业著作时，重点关注三个问题：①这本书的核心主张是什么？②证据/论证是否充分？③对你的领域/生活有什么启发？不必纠结于专业细节。

本体裁根据子类型灵活选择分析维度。

### 通用维度（所有专业著作适用）

#### 维度一：核心知识大白话 ⭐

**分析问题**：这本书最核心的知识是什么？用大白话说清楚。

**方法指引**：
1. 提取核心知识点
2. 每个知识点用大白话解释
3. 标注原文依据
4. 用生活案例辅助解释

**输出格式**：

```markdown
## 核心知识（大白话版）

### 知识点1：[标题]
- 大白话解释：[用日常语言讲清楚]
- 原文依据：[引用原文]
- 生活案例：[用生活中的例子辅助理解]

### 知识点2：[标题]
...
```

#### 维度二：权威性评估 ⭐

**分析问题**：这本书靠不靠谱？

**方法指引**：
1. 作者背景：作者是这个领域的专家吗？
2. 内容时效：知识是否过时？
3. 偏见风险：作者有没有立场偏向？
4. 用大白话表达

**输出格式**：

```markdown
## 权威性评估

### 作者背景
[作者是不是这个领域的专家？]

### 内容时效
[知识是否过时？出版年份是？]

### 偏见风险
[作者有没有立场偏向？]
```

#### 维度三：对我的启示 ⭐

**分析问题**：这些专业知识，如何指导我的生活/工作？

**方法指引**：
1. 这本书能解释哪些日常困惑？
2. 能指导哪些实际决策？（健康/法律/教育/消费）
3. 读完后，我的认知有什么改变？
4. 有哪些可以立即尝试的"行动清单"？
5. 这本书改变了我对XX领域的什么看法？
6. 我以后遇到XX问题时会怎么做？

**输出格式**：

```markdown
## 对我的启示

### 解释日常困惑
- [困惑1]：[书中知识如何解释]
- [困惑2]：[书中知识如何解释]

### 指导实际决策
- [决策场景1]：[书中知识如何指导]
- [决策场景2]：[书中知识如何指导]

### 认知改变
[这本书改变了我对XX领域的什么看法？]

### 行动清单
[若干条可以立即尝试的行动]
```

### 按子类型的实用维度

#### 维度四：实用建议 ⭐（按子类型选择）

**法律应用**：
- 核心法律规则大白话
- 对普通人的法律启示

**医学应用**：
- 健康行为建议（饮食/运动/睡眠/心理）
- 就医信号：什么情况下该就医？

**教育应用**：
- 教育理念大白话
- 对家长/教师的启示

**百科/工具**：
- 知识组织方式
- 如何使用这本书

**学术论文**：
- 研究问题和核心发现大白话
- 对非专业读者的启示

### 通用扩展维度

#### 维度五：专业分析深度（扩展，专业人士适用）

**法律**：法条+推理+判例
**医学**：循证+临床意义
**教育**：理念+应用
**论文**：方法+发现
**百科**：组织+检索

#### 维度六：写作与论证艺术（扩展）

**分析问题**：作者如何论证自己的观点？

**方法指引**：
1. 论证结构：如何组织论证？
2. 证据运用：如何使用证据？
3. 表达技巧：如何让专业内容变得易懂？

## 执行步骤

```
Step 1: 通读全书，提取核心知识点
Step 2: 用大白话解释每个知识点
Step 3: 评估权威性（作者背景、时效、偏见）
Step 4: 提炼实用建议和对我的启示
Step 5: 简述专业分析深度（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个懂专业的朋友在和你聊天
- 用大白话讲清楚专业知识，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这个概念的意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "这个知识可以用在……"
- "作者是这个领域的专家/这本书可能有点过时，因为……"

### 禁忌用语
- 不要堆砌专业术语而不解释
- 不要进行诊断性表述（医学）
- 不要代替法院做"合法/违法"判断（法律）

## 常见陷阱

1. **术语轰炸**：堆砌专业术语而不解释 → 首次出现时用大白话解释
2. **学术化分析**：用评估专业论文的标准分析普及读物 → 普通读者关心的是"能不能用"
3. **越界判断**：代替专业人士做判断 → 明确局限
4. **与我无关**：不联系自身 → 专业书的最终价值是指导生活

---

*专业参考分析的关键是：在专业与普及之间找到平衡——既保持专业的严谨性，又让非专业读者能够理解。*
