# biography.md — 人物分析框架

> 适用：人物传记、回忆录、书信集、日记、口述历史等关于真实人物的著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：编年体（按时间顺序）或 主题体（按主题分章）
- **语言**：叙事性、基于事实、有史料引用、第一或第三人称
- **篇幅**：通常 200-500 页
- **标志词**："出生于""那一年""据记载""回忆录""口述""亲爱的""见字如面"

### 常见子类型
- 自传（《富兰克林自传》《假如给我三天光明》）
- 他传（《史蒂夫·乔布斯传》《苏轼传》）
- 回忆录（《追忆似水年华》《我们仨》）
- 书信集（《傅雷家书》《曾国藩家书》《两地书》）
- 日记（《安妮日记》《鲁迅日记》《胡适日记》）
- 口述历史（《巨流河》《定西孤儿院纪事》）

### 易混淆体裁及区分要点
- vs **小说**：传记基于真实人物和事件，小说是虚构的
- vs **历史**：传记聚焦个体生命，历史聚焦事件/制度
- vs **散文**：传记/书信有明确的私人语境和真实性，散文更公共

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：人生弧线 ⭐

**分析问题**：一生如何展开？

**方法指引**：
1. 时间轴构建：从出生到死亡/当前的关键节点
2. 关键转折点：哪些事件改变了人生轨迹？
3. 人生阶段划分：可分几个阶段？每个阶段的特点？
4. 命运与选择：哪些是时代造就、哪些是个人选择？

**输出格式**：

```markdown
## 人生时间轴

### 关键节点
| 时间 | 年龄 | 事件 | 影响 |
|------|------|------|------|
| ... | ... | ... | ... |

### 人生阶段
- [阶段1]：...（特点：...）
- [阶段2]：...（特点：...）
```

### 维度二：时代背景 ⭐

**分析问题**：什么环境塑造了TA？

**方法指引**：
1. 历史语境：什么时代？什么社会？
2. 时代与个人的互动：时代如何影响TA？TA如何影响时代？
3. 历史情境还原：当时的社会/政治/文化环境
4. 同时代人与TA的比较

### 维度三：关键抉择 ⭐

**分析问题**：最重要的选择是什么？

**方法指引**：
1. 决策分析：面临什么选择？选项有哪些？
2. 决策动机：为什么这样选择？
3. 决策后果：选择带来了什么？
4. 替代可能：如果选了另一条路会怎样？

### 维度四：性格驱动 ⭐

**分析问题**：什么特质推动了TA？

**方法指引**：
1. 核心性格：TA最显著的性格特征
2. 价值观：TA最看重什么？
3. 动机分析：驱动TA的核心动力是什么？
4. 性格与命运：性格如何影响人生走向？

### 维度五：多面性呈现 ⭐

**分析问题**：优点与缺陷如何平衡？

**方法指引**：
1. 光辉面：TA的成就/优点
2. 阴暗面：TA的缺点/争议
3. 争议事件：有哪些争议性事件？
4. 不同视角：不同立场的人如何评价TA？

 
 ### 维度六：对我的启示 ⭐

**分析问题**：从TA的人生中，我能学到什么？

**方法指引**：
1. 传主面对困境时如何应对？对我有什么启发？
2. 传主的关键选择，如果是我会怎么做？
3. 传主的人生遗憾，我能避免吗？
4. 读完这本书，我打算在哪件事上做出改变？

**输出格式**：

```markdown
## 对我的启示

### 面对困境
[传主如何面对困境，对我的启发]

### 关键选择
[传主的选择，如果是我会怎么做]

### 人生遗憾
[传主的遗憾，我能避免什么]

### 行动改变
[读完我打算在哪件事上做出改变]
```



### 维度七：关系网络（扩展）

**分析问题**：关键人物对传主的影响？

**方法指引**：
1. 核心关系：谁对TA影响最大？
2. 关系类型：家庭/师友/对手/合作伙伴
3. 关系动态：关系如何变化？
4. 社会关系图谱：TA的关系网络

### 维度八：自我书写（书信/日记适用，扩展）

**分析问题**：如何书写自我？

**方法指引**：
1. 自我呈现：如何呈现自己？
2. 自我反思：是否有自我反思？
3. 情感真实：情感的真实性如何？
4. 私人语境：在什么私人语境下书写？

### 维度九：史料价值（扩展）

**分析问题**：有什么史料价值？

**方法指引**：
1. 一手/二手来源标注
2. 史料可信度：来源是否可靠？有无交叉验证？
3. 偏见识别：作者是否有立场偏向？
4. 空白与疑点：哪些地方信息不足或有争议？

### 维度十：历史定位（扩展）

**分析问题**：这个人在历史中的位置？

**方法指引**：
1. 历史影响：对后世的深远影响
2. 名声演变：去世后的评价如何变化？
3. 作者视角：作者与传主的关系？写作动机？

## 执行步骤

```
Step 1: 通读全书，标记时间线和关键事件
Step 2: 构建人生时间轴，划分人生阶段
Step 3: 分析时代背景，还原历史情境
Step 4: 识别关键抉择，分析决策逻辑
Step 5: 分析性格驱动，理解核心动机
Step 6: 呈现多面性，平衡优缺点
Step 7: 分析关系网络，理解人际影响
Step 8: 分析自我书写（书信/日记适用）
Step 9: 评估史料价值，识别偏见
Step 10: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 客观中立的叙述 + 适度的共情理解
- 像一个资深传记评论家

### 示范句式
- "XX岁那年，一个改变一生的选择摆在TA面前……"
- "从史料来看，这一事件的真实性存在争议……"
- "要理解TA的这个决定，我们需要回到当时的历史情境……"

### 禁忌用语
- 不要过度美化或过度贬低传主
- 不要忽视史料的局限性
- 不要把传记分析变成人物崇拜/攻击

## 常见陷阱

1. **英雄化/妖魔化**：过度美化或贬低传主 → 保持客观平衡
2. **脱离时代**：用今天的标准评判历史人物 → 回到历史情境
3. **线性叙事**：只按时间顺序叙述 → 分析应有洞见
4. **忽视多面性**：只呈现一面 → 呈现优缺点和争议
5. **与我无关**：不联系自身 → 传记的最终价值是启发自己
---

*人物分析的关键是：在事实与叙事之间找到平衡——既尊重事实的准确性，又理解叙事的选择性。*

## 补充维度：内心世界（核心）

**分析问题**：传主心里在想什么？

**方法指引**：
1. 情感生活：传主快乐/痛苦/挣扎的时刻
2. 内心冲突：传主面临的两难选择
3. 私人情感：信件/日记中流露的真实情感

**输出格式**：

```markdown
## 内心世界

### 情感生活
[传主快乐/痛苦/挣扎的时刻]

### 内心冲突
[传主面临的两难选择]

### 私人情感
[信件/日记中流露的真实情感]
```
