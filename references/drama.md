# drama.md — 戏剧分析框架

> 适用：话剧、歌剧、戏曲、舞剧文本等戏剧作品。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：场次/幕次结构（第一幕、第二幕...或第一场、第二场...）
- **语言**：**对白为主**，配有舞台指示（括号内的动作/走位/场景说明）
- **篇幅**：独幕剧到多幕剧不等
- **标志词**："幕启""幕落""舞台指示""人物表""台词前缀"

### 常见子类型
- 话剧（《雷雨》《茶馆》《哈姆雷特》）
- 歌剧（《茶花女》《图兰朵》）
- 戏曲（京剧、昆曲等，唱念做打）
- 独幕剧（《压迫》《三块钱国币》）
- 荒诞派戏剧（《等待戈多》）

### 易混淆体裁及区分要点
- vs **小说**：戏剧纯靠对白和舞台指示叙事，无叙述者旁白
- vs **诗歌**：戏剧以叙事/冲突为主，诗歌以抒情为主

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：冲突结构 ⭐

**分析问题**：核心冲突是什么？如何展开？

**方法指引**：
1. 核心冲突识别：人vs人 / 人vs社会 / 人vs自我 / 人vs命运
2. 冲突升级曲线：交代 → 发展 → 高潮 → 回落 → 结局
3. 冲突的爆发点：何时达到顶点？

**输出格式**：

```markdown
## 冲突结构

### 核心冲突
- 类型：[人vs人/社会/自我/命运]
- 表述：[A] 在 [处境] 下，必须在 [X] 和 [Y] 之间做出选择

### 冲突升级
| 阶段 | 幕/场 | 冲突强度 | 关键事件 |
|------|-------|----------|----------|
| 交代 | ... | ★★ | ... |
| 发展 | ... | ★★★ | ... |
| 高潮 | ... | ★★★★★ | ... |
| 回落 | ... | ★★★ | ... |
| 结局 | ... | ★ | ... |
```

### 维度二：对白分析 ⭐

**分析问题**：台词如何塑造人物/推动剧情？

**方法指引**：
1. 对白功能分类：推进剧情/揭示性格/制造冲突/营造氛围
2. 潜台词分析：角色没说出来的话是什么？
3. 对白节奏：快慢、长短、停顿的效果
4. 个性化程度：每个角色的语言是否有辨识度？

### 维度三：角色塑造 ⭐

**分析问题**：角色如何立起来？

**方法指引**：
1. 角色功能：主角/对手/导师/伙伴/信使/小丑……
2. 角色对比：对立角色间的反差
3. 角色发展弧线：从第一幕到最后一幕的变化
4. 角色关系网络：谁和谁的关系最核心？

### 维度四：舞台指示 ⭐

**分析问题**：如何为演出服务？

**方法指引**：
1. 舞美设计：舞台布景、灯光、音效提示
2. 空间调度：角色走位、上下场设计
3. 象征性道具：关键物品的象征意义
4. 时空处理：时间跨度、场景转换

### 维度五：结构类型（扩展）

**分析问题**：属于哪种戏剧结构？

**方法指引**：
1. 锁闭式（回顾式）：从高潮前切入，用回顾交代前因
2. 开放式（叙事式）：按时间顺序从头展开
3. 人像展览式：多组人物、多线并进的群像结构
4. 悲剧/喜剧/正剧的判断

### 维度六：主题思想 ⭐

**分析问题**：超越剧情的普遍意义？

**方法指引**：
1. 时代批判：对当时社会的批判/反思
2. 人性探讨：对人性的深层揭示
3. 当代回响：对今天的启示

### 维度七：语言风格（扩展）

**分析问题**：这部戏剧的语言有何特色？

**方法指引**：
1. 对白风格：诗意/口语/文雅/粗俗？
2. 语言个性：不同角色的语言是否有辨识度？

## 执行步骤

```
Step 1: 通读剧本，标记场次/幕次结构
Step 2: 识别核心冲突和冲突升级曲线
Step 3: 分析对白（功能、潜台词、节奏）
Step 4: 分析角色塑造（功能、对比、弧线）
Step 5: 分析舞台指示（舞美、道具、时空）
Step 6: 判断体裁类型和结构类型
Step 7: 挖掘主题思想和当代意义
Step 8: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 兼具文学分析与剧场感
- 适度使用戏剧术语，首次出现时解释

### 句式特征
- 准确、有剧场感
- 分析要有画面感，让读者仿佛置身舞台

### 示范句式
- "第一幕开场，仅用一个场景就把观众拉入了紧张的氛围。"
- "这句台词的潜台词远比字面意思更丰富：……"
- "从戏剧结构来看，第X幕承担的是'高潮对决'的功能。"

### 禁忌用语
- 不要只分析剧情不分析戏剧形式
- 不要把剧本当成小说来分析（忽视舞台性）

## 常见陷阱

1. **小说化分析**：把剧本当成小说来分析 → 戏剧的核心是冲突和对白
2. **忽视舞台性**：只分析文本不分析演出可能性 → 舞台指示是重要分析对象
3. **剧情摘要**：变成"这部剧讲了……" → 分析应有洞见
4. **忽视体裁差异**：用同一套框架分析所有戏剧 → 悲剧/喜剧/荒诞派的分析侧重不同

---

*戏剧分析的独特之处在于"舞台性"——一切分析都要考虑"如果搬上舞台会怎样"。*
