# poetry_prose.md — 诗歌/散文分析框架

> 适用：古体诗、近体诗、现代诗、散文诗、抒情散文、叙事散文、哲理散文、随笔等。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：分行/分节（诗歌）或 段落体（散文）
- **语言**：高度凝练、意象密集、情感浓缩
- **篇幅**：通常短小（几行到几千字），可分析单篇也可分析文集
- **标志词**：意象词、情感词、韵律感、第一人称叙述、个人感悟

### 常见子类型
- 古体诗/近体诗（《将进酒》《春江花月夜》）
- 现代自由诗（《面朝大海》《再别康桥》）
- 散文诗（《野草》中的部分作品）
- 词/曲（宋词、元曲）
- 抒情散文（《背影》《荷塘月色》）
- 叙事散文（《从百草园到三味书屋》）
- 哲理散文（《我与地坛》《热爱生命》）
- 随笔/杂文（《雅舍小品》《野草》部分篇目）
- 文化散文（《文化苦旅》《文明的碎片》）

### 易混淆体裁及区分要点
- vs **小说**：诗歌/散文基于真实经验或抒情，小说是虚构叙事
- vs **戏剧**：诗歌/散文以抒情/叙事为主，戏剧以冲突/对白为主

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **初学者精简版**：如果是第一次分析诗歌/散文，只需完成核心5维度——情感结构、意境营造、语言风格、思想内核、意象/神聚之线。

本体裁根据诗歌/散文选择不同分析维度。

### 通用维度（诗歌+散文适用）

#### 维度一：情感结构 ⭐

**分析问题**：情感如何流动和变化？

**方法指引**：
1. 逐句/节/段标注情感基调（积极/消极/中性）
2. 标注情感强度（1-5级）
3. 识别情感转折点
4. 绘制情感起伏曲线

**输出格式**：

```markdown
## 情感曲线

行/节  情感基调  强度
1-2    惆怅      ★★★
3-4    激昂      ★★★★★  ← 情感高潮
5-6    平静      ★★
7-8    悲凉      ★★★★

[情感转折分析]
```

#### 维度二：意境营造 ⭐

**分析问题**：整体意境属于什么类型？如何营造？

**方法指引**：
1. 意境类型判断：雄浑、婉约、空灵、悲壮、清幽、豪放……
2. 情景关系：触景生情 / 寓情于景 / 情景交融
3. 虚实手法：哪些是实写、哪些是虚写、如何相生
4. 留白分析：哪些东西没说出来，留给读者想象

#### 维度三：语言风格 ⭐

**分析问题**：文字的特色是什么？

**方法指引**：
1. 修辞特色：常用哪些修辞？
2. 句式节奏：长句/短句/整句/散句的搭配
3. 语体特征：质朴/华丽/隽永/俚俗/文白夹杂
4. 用词偏好：口语化/书面化、动词/形容词使用特点

#### 维度四：思想内核 ⭐

**分析问题**：作者想表达什么深层思考？

**方法指引**：
1. 显性观点：直接表达的思想
2. 隐性态度：未明说但字里行间透露的态度
3. 哲理深度：对人生/社会/自然的思考层次
4. 价值取向：作者推崇什么、批判什么

### 诗歌专用维度

#### 维度五：意象系统 ⭐

**分析问题**：核心意象有哪些？它们如何关联？

**方法指引**：
1. 提取核心意象：自然意象/人文意象/抽象意象
2. 意象关联：对比、递进、呼应关系
3. 意象演变：追踪核心意象在诗中的变化轨迹

**输出格式**：

```markdown
## 意象图谱

### 核心意象
| 意象 | 出现位置 | 象征意义 | 情感色彩 |
|------|----------|----------|----------|
| 月 | 第1/5/8行 | 思乡/永恒 | 清冷、孤独 |
| 水 | 第3/7行 | 流逝/无常 | 哀愁 |
```

#### 维度六：诗歌技法（扩展）

**分析问题**：诗歌的艺术技巧有哪些？

**方法指引**：
1. 声律：格律/韵脚/节奏（古体诗）；音步/跨行效果（自由诗）
2. 锤炼：诗眼/炼字/修辞手法/句式特点
3. 章法：起承转合/首尾呼应

### 散文专用维度

#### 维度七：神聚之线 ⭐

**分析问题**：形散神聚的"神"是什么？

**方法指引**：
1. 主题句提取：找出直接或间接表达主旨的句子
2. 情感/思想主线追踪
3. 线索串联：时间线/空间线/情感线/物件线/人物线

#### 维度八：叙事视角（扩展）

**分析问题**：谁在讲、对谁讲、怎么讲？

**方法指引**：
1. 人称分析：第一/二/三人称
2. 视角转换：是否有视角变化？
3. 语气特征：亲切/疏离/自嘲/反讽/平静/激昂

#### 维度九：素材组织（扩展）

**分析问题**：材料如何组织？

**方法指引**：
1. 选材特点：选了什么素材？
2. 详略安排：哪些详写、哪些略写？
3. 虚实结合：写实与想象的搭配

#### 维度十：创作背景（扩展）

**分析问题**：在什么情境下创作？

**方法指引**：
1. 创作时间：何时创作？当时的社会/文化背景？
2. 创作动机：作者为何写这首诗/这篇散文？
3. 作者处境：作者当时的人生状态如何？
4. 创作情境：哪些经历/事件直接触发了创作？

#### 维度十一：比较文学（扩展）

**分析问题**：与同类作品相比有何特色？

**方法指引**：
1. 同主题对比：与其他作品写同一主题有何不同？
2. 同作者对比：与作者其他作品相比有何变化？
3. 同时代对比：与同时代作品相比有何独特之处？
4. 跨文化对比：不同文化中的相似作品有何异同？

## 文集/选集处理规则

诗歌集、散文集、随笔集等**文集类书籍**通常包含多篇独立作品（少则十几篇，多则上百篇/首），**不可逐一全部分析**。检测到文集时，按以下规则处理：

### 识别信号
- 书名含"集""选""文集""诗集""散文集""随笔集""诗选"
- 目录显示独立篇目/篇名
- 各篇/首之间无连续叙事关系

### 处理流程

**Step 1**：统计全书篇/首数，向用户说明情况

```
这本书是[诗歌/散文]集，共收录 N [篇/首]。由于篇幅原因，无法逐一分析。我建议以下几种方式：

1️⃣ **精选深析** — 我为你挑选 5-8 [篇/首]最具代表性的作品逐一分析
2️⃣ **你选我析** — 你指定感兴趣的[篇/首]目（如"分析第3、7、15[篇/首]"或给出标题）
3️⃣ **整体概览** — 全书综述（主题脉络、风格演变、核心思想）+ 重点[篇/首]目 2-3 [篇/首]深析

你想用哪种方式？
```

**Step 2**：按用户选择执行

| 用户选择 | 执行方式 |
|---------|---------|
| 精选深析 | 挑选标准：知名度高、风格多样、思想深度强、代表作者不同时期 |
| 你选我析 | 按用户指定篇/首目逐一分析 |
| 整体概览 | 先全书综述，再选 2-3 篇/首代表作深析 |

### 精选深析的挑选标准
- **代表作**：作者最知名的篇/首作
- **多样性**：涵盖作者不同题材/风格/时期
- **思想深度**：最能体现作者核心思想的篇/首作
- **技巧代表性**：写作技法最有特色的篇/首作

### 输出结构（精选深析）

```markdown
# [诗歌/散文]集分析：《书名》| YYYY-MM-DD

## 📋 基本信息
- 书名：
- 作者/编者：
- 体裁：[诗歌集/散文集/随笔集]
- 全书[篇/首]数：N
- 本次分析：精选 M [篇/首]

## 🎯 全书概览
[全书主题脉络、风格特征、核心思想概述]

## 📊 逐[篇/首]分析

### [篇/首]目1：《标题》
[按单[篇/首]分析维度展开]

### [篇/首]目2：《标题》
[按单[篇/首]分析维度展开]
...

## 📈 整体风格演变
[各[篇/首]之间的风格变化、思想发展脉络]

## 💡 关键洞察
[3-5个关于作者/文集整体的重要发现]

## 📝 金句精选
[精选全书金句，每[篇/首] 1-2 条]

## 🧭 一句话总结
[全书核心价值]
```

### 边界情况
- **诗歌集短篇（≤10首）**：可询问用户"全书共 X 首，篇幅较短，是否需要全部分析？"
- **散文集短篇（≤5篇）**：可询问用户"全书共 X 篇，篇幅较短，是否需要全部分析？"
- **长篇文集（>20篇/首）**：强制精选，不询问全部分析
- **主题文集（如《文化苦旅》各篇有内在关联，《唐诗三百首》按题材编排）**：整体概览优先，精选为辅
- **多人选集（如《朦胧诗选》《中国现代散文选》）**：挑选不同作者代表作，体现选集广度

## 语气风格规范

### 称呼方式
- 诗意化、审美化，适度使用文学批评术语
- 可用"我们"引导读者进入文本世界

### 句式特征
- 凝练优美，与诗歌/散文分析内容相匹配
- 分析要有画面感，让读者仿佛看到/感受到文字之美

### 示范句式
- "首联以……起笔，营造出……的氛围。"
- "一个'X'字，化静为动，将……写得栩栩如生。"
- "全文的情感轨迹可以概括为：从……到……的升华。"
- "开篇仅用一句话，就把我们带入了……的场景。"

### 禁忌用语
- 不要过度解读（无文本依据的"深层含义"）
- 不要堆砌空洞的赞美词
- 不要把诗歌分析变成白话翻译
- 不要变成内容摘要

## 常见陷阱

1. **白话翻译**：把分析变成"这首诗的意思是……" → 分析应有深度
2. **过度解读**：无文本依据的"深层含义" → 所有分析必须有原文支撑
3. **忽视声音**：只分析内容不分析韵律 → 诗歌的声音层面是重要维度
4. **空泛赞美**：堆砌"千古名句""意境优美"等空话 → 具体分析美在哪里
5. **割裂整体**：逐句分析后没有整合 → 必须给出整体判断

---

*诗歌/散文分析的关键是：在感性体验与理性分析之间找到平衡——既要"入乎其内"感受情感，又要"出乎其外"分析技巧。*
