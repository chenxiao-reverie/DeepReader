# fiction.md — 小说/故事分析框架

> 适用：长篇小说、中短篇小说、童话故事、民间故事、寓言等叙事文学作品。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：章节体/故事集，有人物、情节、环境
- **语言**：叙事性语言、人物对话、场景描写
- **篇幅**：差异极大（短篇几千字到长篇数百万字）
- **标志词**：人物对话、场景描写、情节推进、"从前""很久很久以前"

### 常见子类型
- 现实主义小说（《活着》《平凡的世界》）
- 幻想/科幻小说（《三体》《魔戒》）
- 推理/悬疑小说（《白夜行》《福尔摩斯》）
- 历史小说（《三国演义》《大秦帝国》）
- 网络小说（玄幻/言情/仙侠等）
- 童话/寓言（《格林童话》《安徒生童话》《伊索寓言》）
- 民间故事/传说（《中国民间故事》《一千零一夜》）
- 古典白话小说（《红楼梦》《水浒传》）

### 易混淆体裁及区分要点
- vs **戏剧**：小说有叙述者视角，戏剧纯靠对白和舞台指示
- vs **散文**：小说有完整虚构叙事，散文基于真实经验
- vs **传记**：小说是虚构人物，传记是真实人物
- vs **神话**：童话/民间故事更世俗化，神话更神圣

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

本体裁根据子类型灵活选择分析维度。

### 通用维度（所有叙事文学适用）

#### 维度一：人物分析 ⭐

| 维度 | 说明 |
|------|------|
| **基础信息** | 姓名、性别、年龄、身份、初登场 |
| **性格标签** | 从行为×他人评价×内心独白三维交叉验证 |
| **心理动机** | 表层"想要" vs 深层"需要" |
| **成长弧光** | 初期→转变→中期→最终 |
| **关键语录** | 代表性对话/独白 |
| **行为事件链** | "事件 → 动机"证据链 |

#### 维度二：剧情结构 ⭐

**三幕剧结构**：

| 节点 | 位置 | 功能 |
|------|------|------|
| 激励事件 | 10%-15% | 打破日常的触发点 |
| 第一幕转折 | 20%-25% | 主角做出不可逆选择 |
| 中点反转 | 45%-55% | 世界观/认知颠覆 |
| 低谷时刻 | 70%-80% | 最大危机/绝望 |
| 高潮对决 | 85%-95% | 核心冲突正面爆发 |
| 结局收束 | 95%-100% | 主题闭环与余韵 |

#### 维度三：主题与象征 ⭐

1. 核心主题：全书想表达什么？
2. 象征系统：反复出现的意象/象征
3. 深层意涵：超越故事的普遍意义

### 小说专用维度

#### 维度四：关系图谱 ⭐

**五大关系类别**：血缘、情感、权力、社交、精神

每条关系包含：类型、强度1-5星、建立章节、转折点、最终状态

#### 维度五：伏笔追踪 ⭐

**六种伏笔类型**：物品预示、对话暗示、意象重复、行为预示、信息缺口、逆向伏笔

评分体系：隐蔽性 × 兑现质量 × 时间跨度 = 悬念指数

#### 维度六：世界观建模（幻想/科幻适用）⭐

**四维框架**：地理、社会、文化、力量体系

#### 维度七：叙事艺术（扩展）

- 叙事视角 + 语言特色 + 叙事节奏

### 童话/民间故事专用维度

#### 维度八：叙事模式 ⭐

- 三段式重复：三个任务/三个兄弟/三个问题
- 程式化特征：开头程式/重复程式/程式化细节
- 口头特征：体现口头传承的特点

#### 维度九：母题分析 ⭐

- 核心母题提取
- 跨文化母题对比
- 母题来源与变体

#### 维度十：道德与文化 ⭐

- 显性寓意：直接表达的道德教训
- 隐性寓意：隐含的价值观
- 文化功能：教育/娱乐/认同/解释
- 儿童心理：对儿童心理发展的意义

#### 维度十一：叙事艺术（扩展）

**分析问题**：作者如何讲这个故事？

**方法指引**：
1. **叙事视角**：第一人称/第三人称？叙事者是否可靠？
2. **语言特色**：简洁/华丽/朴实/幽默？修辞手法？
3. **叙事节奏**：时间安排（顺叙/倒叙）？节奏变化？

## 语气风格规范

### 称呼方式
- 根据子类型切换：小说偏学术化，童话偏温暖
- 可用"我们"引导分析

### 句式特征
- 准确、有文学批评的专业感
- 适度使用文学理论术语，首次出现时解释
- 分析要有画面感，让读者仿佛进入故事世界

### 示范句式
- "从叙事结构来看，第X章承担的是'中点反转'的功能。"
- "值得注意的是，这个意象在全文中出现了N次，构成了一条隐性线索。"
- "这个童话母题在世界各地都有变体……"

### 禁忌用语
- 不要把分析变成剧情复述
- 不要强行把文本套入理论模型
- 不要忽视文本证据空谈感受

## 常见陷阱

1. **摘要化**：把分析变成剧情复述 → 分析应有洞见
2. **过度拟合**：强行把文本套入理论模型 → 尊重文本自身结构
3. **人物遗漏**：只分析主角忽略配角 → 按重要性覆盖
4. **孤立分析**：各维度独立输出不整合 → 维度间数据应互证
5. **忽视子类型**：用同一套权重分析所有叙事 → 根据类型调整侧重

---

*叙事文学分析的关键是：在故事与意义之间找到平衡——既享受阅读的乐趣，又理解作品背后的深度。*
