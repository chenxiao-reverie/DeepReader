# arts.md — 艺术分析框架

> 适用：艺术史、美学理论、美术/音乐/建筑/电影/设计等艺术著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：时间线/流派线/主题线组织
- **语言**：博雅通达，有审美敏感，适度使用美学/艺术术语
- **篇幅**：通常 200-500 页（艺术史类可能更厚）
- **标志词**："美学""流派""风格""构图""色彩""形式""表现""审美"

### 常见子类型
- 艺术史（《艺术的故事》《加德纳艺术通史》）
- 美学理论（《美学散步》《判断力批判》）
- 绘画分析（《西方绘画大师》《梵高传》中的分析部分）
- 音乐分析（《听音乐》《西方文明中的音乐》）
- 建筑分析（《建筑十书》《走向新建筑》）
- 电影分析（《认识电影》《电影艺术：形式与风格》）
- 设计理论（《设计中的设计》《写给大家看的设计书》）

### 易混淆体裁及区分要点
- vs **历史**：艺术史侧重艺术作品/流派的审美分析，历史侧重事件/制度
- vs **自然科学**：艺术以主观审美为核心，自然科学以客观规律为核心
- vs **哲学**：美学是哲学的分支，但艺术分析更侧重具体作品

## 艺术普及 vs 学术专著区分处理

艺术著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **艺术普及** | 面向大众、图文并重、语言通俗、重启发和欣赏 | 《艺术的故事》《写给大家看的设计书》《认识电影》《听音乐》 |
| **学术专著** | 面向学者、术语密集、理论性强、引用文献 | 《判断力批判》《加德纳艺术通史》（学术版）《美学散步》 |

### 处理规则

**艺术普及（占大多数）**：
- 核心目标：让读者"获得审美启发、学会欣赏"
- 侧重：核心美学观点大白话、作品分析（简化）、鉴赏方法、对我的启示
- 弱化：美学理论流派、艺术史定位、接受史（可提及但不深入分析）

**学术专著（占少数）**：
- 核心目标：理解美学理论和艺术史方法
- 保留专业分析维度（美学理论、艺术史定位、接受史）

> ⚠️ **默认按艺术普及处理**，除非明显是学术专著（术语密集、理论性强、引用文献）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按艺术普及维度执行**，学术专著可保留"美学理论""艺术史定位""接受史"等专业维度。

### 维度一：核心美学观点大白话 ⭐

**分析问题**：这本书认为"什么是美"？用大白话说清楚。

**方法指引**：
1. 提取核心美学观点
2. 每个观点用大白话解释
3. 标注原文依据
4. 用生活场景辅助解释

**输出格式**：

```markdown
## 核心美学观点（大白话版）

### 观点1：[标题]
- 大白话解释：[用日常语言讲清楚]
- 原文依据：[引用原文]
- 生活场景：[什么时候能感受到这种美？]

### 观点2：[标题]
...
```

### 维度二：作品分析 ⭐

**分析问题**：具体作品好在哪里？

**方法指引**：
1. 挑选核心作品
2. 用大白话描述作品给人的感受
3. 简述技法和风格特征（不需要专业术语）
4. 标注原文依据

**输出格式**：

```markdown
## 作品分析

### 作品1：[名称]
- 给人的感受：[用大白话描述]
- 技法和风格：[用大白话简述]
- 原文依据：[引用原文]

### 作品2：[名称]
...
```

### 维度三：鉴赏方法 ⭐

**分析问题**：如何观看/欣赏？

**方法指引**：
1. 观看顺序：先看什么、后看什么？
2. 关注重点：最值得关注的细节
3. 入门路径：从哪些作品开始？

### 维度四：对我的启示 ⭐

**分析问题**：这些艺术观点，如何改变我的审美？

**方法指引**：
1. 这本书能解释哪些日常审美困惑？
2. 能指导哪些日常决策？（穿衣/装修/看电影/听音乐）
3. 读完后，我欣赏艺术的眼光有什么不同？
4. 有哪些可以立即尝试的"审美练习"？

**输出格式**：

```markdown
## 对我的启示

### 解释日常困惑
- [困惑1]：[书中观点如何解释]
- [困惑2]：[书中观点如何解释]

### 指导日常决策
- [决策场景1]：[书中观点如何指导]
- [决策场景2]：[书中观点如何指导]

### 审美练习
[若干个可以立即尝试的练习]
```

### 维度五：艺术史脉络（扩展，学术研究适用）

**分析问题**：在艺术史中的位置？

**方法指引**：
1. 时代背景：什么时代产生了这些作品？
2. 流派关系：属于什么流派？与其他流派的关系？
3. 影响谱系：影响了后来的哪些艺术家/流派？

### 维度六：接受史（扩展，学术研究适用）

**分析问题**：历代评价如何变迁？

**方法指引**：
1. 当代评价：同时代人怎么看？
2. 历代接受：评价如何随时间变化？
3. 经典化过程：如何成为"经典"？

### 维度七：创作论（扩展）

**分析问题**：艺术家如何创作？

**方法指引**：
1. 创作理念：艺术家/作者的创作主张
2. 创作过程：如何从无到有？
3. 艺术家意图：想表达什么？

## 执行步骤

```
Step 1: 通读全书，提取核心美学观点
Step 2: 用大白话解释每个观点
Step 3: 分析核心作品，用大白话描述感受
Step 4. 提炼鉴赏方法和对我的启示
Step 5: 简述艺术史脉络和接受史（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个美术馆导览员在和你聊天
- 用大白话讲清楚美，拒绝"术语轰炸"
- 可以用"我们"引导读者进入艺术世界

### 示范句式
- "用大白话来说，这幅画/这本书的意思是……"
- "站在作品面前，最先吸引我的是……"
- "读完这个，我原来以为___，现在知道了___"
- "要欣赏这类作品，我们可以先……"

### 禁忌用语
- 不要堆砌"形式主义""接受美学"等术语
- 不要武断的唯一解读（"这件作品的意思就是……"）
- 不要堆砌空洞的赞美词（"美轮美奂""无与伦比"）

## 常见陷阱

1. **术语轰炸**：堆砌"形式主义""接受美学"等术语 → 用大白话讲美
2. **学术化分析**：用评估学术论文的标准分析艺术普及 → 普通读者关心的是"怎么欣赏"
3. **知识罗列**：变成艺术史知识清单 → 分析应有洞见
4. **与我无关**：不联系自身 → 艺术的最终价值是启发自己

---

*艺术分析的关键是：既有审美的敏感（感受美），又有学术的深度（理解美），还有开放的心态（尊重多元解读）。*

## 补充维度

### 创作背景故事（核心）

**分析问题**：艺术家创作时经历了什么？

**方法指引**：
1. 艺术家的人生转折点
2. 创作时的故事（如梵高割耳、贝多芬失聪）
3. 时代背景对创作的影响

**输出格式**：

```markdown
## 创作背景故事

### 艺术家的人生转折点
[艺术家的人生转折点]

### 创作时的故事
[创作时的故事]

### 时代背景的影响
[时代背景对创作的影响]
```

### 情感体验（核心）

**分析问题**：这件作品让你感受到了什么？

**方法指引**：
1. 第一反应：看完/听完的第一感受
2. 情感变化：欣赏过程中的情绪起伏
3. 个人联想：让你想到了什么经历/记忆

**输出格式**：

```markdown
## 情感体验

### 第一反应
[看完/听完的第一感受]

### 情感变化
[欣赏过程中的情绪起伏]

### 个人联想
[让你想到了什么经历/记忆]
```
