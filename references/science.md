# science.md — 科学分析框架

> 适用：物理学、化学、生物学、天文学、数学、逻辑学等自然科学与形式科学著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→假说→实验→结论 或 定义→公理→定理→证明
- **语言**：准确、客观、逻辑严密，有公式/数据/图表
- **篇幅**：差异大（科普读物到学术专著）
- **标志词**："实验表明""数据显示""假说""定理""公式""可重复""公理""证明"

### 常见子类型
- 物理学科普（《时间简史》《宇宙的琴弦》）
- 生物学科普（《自私的基因》《枪炮、病菌与钢铁》）
- 数学普及（《数学之美》《从一到无穷大》）
- 逻辑学（《逻辑学导论》《哥德尔证明》）
- 环境/地球科学（《寂静的春天》《第六次大灭绝》）
- 科学史/科学哲学（《科学革命的结构》《万物简史》）

### 易混淆体裁及区分要点
- vs **社会科学**：自然科学侧重可量化的自然现象和实验验证，社会科学侧重人类社会
- vs **人文艺术**：自然科学以客观规律为核心，人文艺术以主观审美为核心

---

## 科普 vs 学术专著区分处理

科学著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **科普读物** | 面向大众、语言通俗、多用类比和案例、无公式推导 | 《时间简史》《自私的基因》《枪炮、病菌与钢铁》《数学之美》《从一到无穷大》《寂静的春天》《万物简史》 |
| **学术专著** | 面向学者、术语密集、公式推导、引用文献 | 《逻辑学导论》《哥德尔证明》《量子力学导论》 |

### 处理规则

**科普读物（占大多数）**：
- 核心目标：让读者"读懂、记住、用上"
- 侧重：概念通俗化、认知改变、日常关联、科普表达评估
- 弱化：实验设计评估、统计显著性、范式转换（可提及但不深入分析）

**学术专著（占少数）**：
- 核心目标：理解理论体系和论证逻辑
- 保留专业分析维度（证据链条、理论演进、争议边界）

> ⚠️ **默认按科普读物处理**，除非明显是学术专著（术语密集、公式推导、面向学者）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按科普读物维度执行**，学术专著可保留"证据链条""争议边界"等专业维度。

### 维度一：核心概念大白话 ⭐

**分析问题**：这本书最核心的科学观点是什么？用大白话能说清楚吗？

**方法指引**：
1. 提取核心概念
2. 每个概念用**一句话大白话**解释（让初中生能听懂）
3. 标注原文中的定义或类比，评估类比是否恰当
4. 概念之间的关系（并列/递进/因果）

**输出格式**：

```markdown
## 核心概念（大白话版）

### 概念1：[名称]
- 大白话解释：[一句话说清楚]
- 原文依据：[引用原文或类比]
- 类比评估：[这个类比好不好懂？有没有更贴切的？]

### 概念2：[名称]
...
```

### 维度二：认知刷新点 ⭐

**分析问题**：这本书如何颠覆或刷新了我们已有的认知？

**方法指引**：
1. 找出"反直觉"或"意想不到"的科学发现
2. 每个发现用"原来我以为……现在知道了……"的格式表达
3. 标注原文依据
4. 评估：这个刷新是"有趣但不重要"还是"改变世界观"

**输出格式**：

```markdown
## 认知刷新

### 刷新点1：[标题]
- 原来我以为：[常见误解]
- 现在知道了：[科学事实]
- 原文依据：[引用原文]
- 重要性：★★★（改变世界观/有趣但不重要）
```

### 维度三：日常关联 ⭐

**分析问题**：这些科学知识，和我的生活有什么关系？

**方法指引**：
1. 这本书的知识能解释哪些日常现象？
2. 能指导哪些日常决策？（健康/消费/教育/职业）
3. 读完后，我看世界的眼光有什么不同？
4. 作者的类比和案例是否贴近生活？

**输出格式**：

```markdown
## 日常关联

### 解释日常现象
- [现象1]：[书中知识如何解释]
- [现象2]：[书中知识如何解释]

### 指导日常决策
- [决策场景1]：[书中知识如何指导]
- [决策场景2]：[书中知识如何指导]

### 认知升级
[读完后，我对XX的理解从___变成了___]
```

### 维度四：理论演进（扩展）

**分析问题**：这个科学理论是怎么来的？

**方法指引**：
1. 用时间线简述发展脉络（关键节点即可）
2. 标注关键人物和贡献
3. 用大白话解释"范式转换"（如有）

**输出格式**：

```markdown
## 理论演进

### 发展脉络
- [年份] [人物] [贡献（大白话）]
- [年份] [人物] [贡献（大白话）]

### 范式转换
[如有，用大白话解释]
```

### 维度六：争议边界（扩展）

**分析问题**：这个理论有哪些争议和局限？

**方法指引**：
1. 用大白话解释当前争议（不深入分析学术分歧）
2. 标注理论适用边界（什么情况下会失效）

**输出格式**：

```markdown
## 争议边界

### 当前争议
[用大白话解释学界有哪些不同观点]

### 理论局限
[在什么情况下会失效]
```

### 维度七：社会影响与伦理（扩展）

**分析问题**：这个科学发现/理论对社会和伦理有什么影响？

**方法指引**：
1. 社会影响：对社会结构/政策/公众认知的影响
2. 伦理讨论：涉及哪些伦理问题？（如AI伦理、基因编辑、隐私）
3. 风险与挑战：可能带来的负面效应
4. 公众责任：科学家和公众应如何应对？

---

## 执行步骤

```
Step 1: 通读全书，提取核心概念
Step 2: 用大白话解释每个概念
Step 3: 找出认知刷新点，用"原来我以为……现在知道了……"表达
Step 4: 关联日常现象和决策场景
Step 5: 简述理论演进和争议边界（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个善于讲解的科学传播者
- 用大白话讲清楚，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这个概念的意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "这个类比很贴切/有点勉强，因为……"
- "作者讲得很清楚/这里有点难懂，可能是因为……"

### 禁忌用语
- 不要堆砌公式和术语而不解释
- 不要评估"统计显著性""变量控制"等专业概念（除非学术专著）
- 不要把科普读物当成教科书分析
- 不要忽视"这本书好不好读"这个核心问题

## 常见陷阱

1. **术语轰炸**：堆砌公式和术语而不解释 → 首次出现时用大白话解释
2. **学术化分析**：用评估学术论文的标准分析科普书 → 普通读者关心的是"懂不懂"，不是"证据强不强"
3. **脱离生活**：不与日常关联 → 每个核心概念都要思考"这和我有什么关系"
4. **与我无关**：不联系自身 → 科学的最终价值是启发自己
5. **过度简化**：为了通俗而失真 → 保持科学的准确性

---

*科学著作分析的关键是：既要有科学的严谨，又要有科普的温度——让读者"懂"且"信"。*

## 补充说明：丰富"对我的启示"维度

在"日常关联"基础上，"对我的启示"应包含：
- **认知改变**：我对XX的理解从___变成了___
- **行为意向**：我接下来一周会尝试什么新做法
- **情感体验**：读完后我的心情/想法有什么变化

## 补充维度：科学思维方法（扩展）

**分析问题**：这本书教了我什么思考方法？

**方法指引**：
1. 科学家怎么想问题：怀疑精神、可证伪性思维、奥卡姆剃刀
2. 相关性≠因果：这个结论是相关还是因果？
3. 思维工具：能迁移到哪些问题？

**输出格式**：

```markdown
## 科学思维方法

### 核心思维工具
[这本书教了我什么思考方法？]

### 可迁移应用
[这些思维工具还能用在哪些问题？]
```
