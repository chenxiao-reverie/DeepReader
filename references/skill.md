# skill.md — 技能学习分析框架

> 适用：语言学习、乐器学习、编程学习、绘画学习、健身训练、烹饪学习、手工技艺、运动技能等技能教程/教材。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：知识单元→技能讲解→示例演示→练习任务
- **语言**：指导性、实用性、多用步骤说明和示例
- **篇幅**：差异大（入门几百页到教材系列）
- **标志词**："第一步""练习""注意""技巧""掌握""入门""进阶""实战"

### 常见子类型
- 语言学习（《新概念英语》《赖世雄美语》《大家的日语》）
- 编程/计算机技术（《Python编程从入门到实践》《算法导论》《代码大全》）
- 乐器学习（《吉他自学三月通》《拜厄钢琴基本教程》）
- 绘画/设计（《伯里曼人体结构》《写给大家看的设计书》）
- 健身/运动（《斯瓦辛格健身全书》《跑步圣经》）
- 烹饪/手工（《随园食单》《木工基础》）
- 职场技能（《PPT设计思维》《Excel数据分析》）

### 易混淆体裁及区分要点
- vs **成长实用类**：技能学习侧重"学会做一件事"，成长类侧重"提升认知/习惯"
- vs **教材/百科**：技能学习强调动手实践，教材侧重系统知识
- vs **自然科学**：编程等计算机技术看似科学，但学习时侧重实操技能

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：知识体系图谱 ⭐

**分析问题**：这门技能的知识/技能点如何组织？

**方法指引**：
1. 知识拆解：这门技能包含哪些核心知识点/技能点？
2. 依赖关系：哪些技能是前置？哪些是进阶？
3. 体系完整性：知识覆盖是否全面？有无遗漏？
4. 组织逻辑：按什么逻辑组织？（难度递进/主题维度/项目驱动）

**输出格式**：

```markdown
## 知识体系图谱

### 核心知识/技能点
| 维度 | 核心内容 | 难度 | 前置要求 |
|------|----------|------|----------|
| ... | ... | ★★ | 无 |
| ... | ... | ★★★ | ... |

### 技能依赖关系
[前置技能 → 进阶技能 → 高级技能]
```

### 维度二：技能阶梯设计 ⭐

**分析问题**：从入门到精通的学习路径是否合理？

**方法指引**：
1. 学习阶段划分：入门→基础→进阶→高级→精通
2. 阶段目标：每个阶段应该达到什么水平？
3. 过渡设计：阶段之间的衔接是否平滑？
4. 梯度评估：难度跳跃是否合理？

**输出格式**：

```markdown
## 技能阶梯

### 学习阶段
| 阶段 | 目标 | 预计耗时 | 检验标准 |
|------|------|----------|----------|
| 入门 | ... | X周 | 能完成... |
| 基础 | ... | X周 | 能完成... |
| 进阶 | ... | X月 | 能完成... |
| 高级 | ... | X月 | 能完成... |
```

### 维度三：练习体系 ⭐

**分析问题**：练习设计是否有效？

**方法指引**：
1. 练习数量：每个知识点的练习量是否充足？
2. 练习难度：练习难度是否循序渐进？
3. 练习类型：模仿练习/变式练习/综合练习/实战练习
4. 反馈机制：如何判断做得对不对？
5. 纠错设计：常见错误是否指出来？

**输出格式**：

```markdown
## 练习体系

### 练习设计
| 类型 | 数量 | 难度梯度 | 反馈机制 |
|------|------|----------|----------|
| 模仿练习 | ... | ... | ... |
| 变式练习 | ... | ... | ... |
| 综合练习 | ... | ... | ... |
| 实战练习 | ... | ... | ... |
```

### 维度四：学习原理 ⭐

**分析问题**：基于什么学习理论？

**方法指引**：
1. 刻意练习：是否有明确目标、即时反馈、突破舒适区？
2. 间隔重复：是否利用记忆曲线安排复习？
3. 项目驱动：是否通过做项目来学习？
4. 费曼技巧：是否鼓励"教给别人"？

### 维度五：实操转化 ⭐

**分析问题**：读者能制定什么学习计划？

**方法指引**：
1. 学习计划：基于本书，可以制定什么学习计划？
2. 时间安排：每天/每周投入多少时间？
3. 里程碑：什么时候应该达到什么水平？
4. 检验标准：如何判断自己学会了？
5. 常见阻碍：学习过程中可能遇到什么问题？

**输出格式**：

```markdown
## 学习计划建议

### 推荐学习计划
| 阶段 | 时间投入 | 学习内容 | 完成标志 |
|------|----------|----------|----------|
| 第1周 | X小时/天 | ... | 能... |
| 第2-4周 | X小时/天 | ... | 能... |
```

### 维度六：教学有效性评估（扩展）

**分析问题**：这本书教得好不好？

**方法指引**：
1. 讲解清晰度：概念讲得清不清楚？
2. 示例质量：例子是否典型、是否充分？
3. 循序渐进：难度递进是否合理？
4. 实用性：学完能不能直接用起来？
5. 与同类比较：相比同类教程有什么优势/不足？

### 维度七：配套资源（扩展）

**分析问题**：有哪些配套学习资源？

**方法指引**：
1. 数字资源：视频/音频/代码/素材
2. 社区支持：是否有学习社区/论坛？
3. 工具推荐：需要什么工具/软件/设备？
4. 进阶资源：学完这本后下一步学什么？

### 维度八：常见错误与避坑（扩展）

**分析问题**：学习这门技能容易踩哪些坑？

**方法指引**：
1. 常见错误：初学者最容易犯的错误
2. 避坑指南：如何避免这些错误？
3. 错误纠正：犯了错如何纠正？
4. 警示信号：什么信号表明学习方法有问题？

## 执行步骤

```
Step 1: 通读全书，拆解知识/技能点
Step 2: 绘制知识体系图谱和技能依赖关系
Step 3: 分析技能阶梯设计
Step 4: 评估练习体系
Step 5: 分析学习原理
Step 6: 制定实操学习计划
Step 7: 评估教学有效性
Step 8: 梳理配套资源
Step 9: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 实用导向、有教学经验
- 像一个资深教练/导师

### 示范句式
- "这本书的知识体系可以概括为……"
- "从技能学习的角度来看，这一章节的设计精妙之处在于……"
- "值得注意的是，这一阶段的练习量可能不足，建议补充……"

### 禁忌用语
- 不要把技能教程当成文学作品分析
- 不要忽视练习体系的重要性
- 不要把学习分析变成内容摘要

## 常见陷阱

1. **文学化分析**：把技能教程当成文学作品分析 → 技能学习的核心是"学会做"
2. **忽视练习**：只分析知识不分析练习 → 练习体系是技能学习的核心
3. **忽视梯度**：不分析难度递进 → 技能阶梯设计是重要维度
4. **忽视反馈**：不分析如何判断对错 → 反馈机制是学习的关键
5. **内容摘要**：变成"这本书讲了……" → 分析应有洞见

---

*技能学习分析的关键是：在知识与行动之间找到平衡——既理解知识体系，又设计有效的学习路径。*
