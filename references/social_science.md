# social_science.md — 社会科学分析框架

> 适用：社会学、政治学、经济学、传播学、演讲修辞等社会科学著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→理论框架→论证→结论 或 现象→分析→解释→启示
- **语言**：学术性、论证性、多用专业概念和理论框架
- **篇幅**：通常 200-400 页
- **标志词**："研究表明""数据显示""理论框架""方法论""样本""变量"

### 常见子类型
- 社会学（《乡土中国》《乌合之众》）
- 经济学（《国富论》《21世纪资本论》《思考，快与慢》经济部分）
- 政治学（《正义论》《独裁者手册》）
- 传播学（《理解媒介》《娱乐至死》《乌合之众》）
- 演讲修辞（《葛底斯堡演说》《我有一个梦想》合集）
- 人类学（《忧郁的热带》《菊与刀》）

### 易混淆体裁及区分要点
- vs **自然科学**：社会科学研究人类社会，难以完全量化实验
- vs **人文艺术**：社会科学侧重客观分析，人文艺术侧重主观审美
- vs **哲学**：社会科学侧重经验研究，哲学侧重概念思辨

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。

### 维度一：核心命题 ⭐

**分析问题**：这本书的核心论点是什么？

**方法指引**：
1. 研究问题提取：作者试图回答什么问题？
2. 核心论点概括：一句话说清核心主张
3. 理论贡献：对学科有什么新贡献？
4. 论点结构：总论点 + 分论点

**输出格式**：

```markdown
## 核心命题

### 研究问题
[作者试图回答的核心问题]

### 核心论点
[一句话概括核心主张]

### 理论贡献
[对学科的新贡献]
```

### 维度二：理论框架 ⭐

**分析问题**：用什么视角看社会？

**方法指引**：
1. 理论流派识别：属于哪个学派/理论传统？
2. 核心概念提取：关键概念及其定义
3. 分析视角：从什么维度切入问题？（阶级/性别/种族/制度/文化……）
4. 与经典理论的对话：继承了什么、修正了什么

**输出格式**：

```markdown
## 理论框架

### 理论流派
[所属学派/理论传统]

### 核心概念
| 概念 | 定义 | 在分析中的作用 |
|------|------|----------------|
| ... | ... | ... |
```

### 维度三：论证逻辑 ⭐

**分析问题**：如何从证据到结论？

**方法指引**：
1. 论点-论据结构：每个论点用什么支撑？
2. 推理链条：推理是否严密？有无逻辑漏洞？
3. 论证方法：归纳/演绎/类比/反证/归谬
4. 反例处理：是否考虑了反面证据？

### 维度四：经验材料 ⭐

**分析问题**：用什么支撑？

> 💡 **外行评估指引**：普通读者评估经验材料时，关注三个问题：①案例是否典型（能代表更大群体）？②数据来源是否可靠（一手调查还是二手引用）？③样本是否够大、够多元？

**方法指引**：
1. 案例选择：用了哪些案例？是否典型？
2. 数据来源：数据从哪里来？是否可靠？
3. 田野调查质量：调查设计是否合理？
4. 材料代表性：能否支撑结论？

**输出格式**：

```markdown
## 经验材料

### 案例/数据
| 材料 | 类型 | 来源 | 代表性评估 |
|------|------|------|-----------|
| ... | 案例/数据/田野 | ... | ★★★★☆ |
```

### 维度五：表达与修辞（扩展）

**分析问题**：如何说服受众？

**方法指引**：
1. 修辞手法：排比/比喻/设问/对比/呼告
2. 写作风格：学术严谨型还是通俗易懂型？

### 维度六：批判反思 ⭐

**分析问题**：不同立场怎么看？

**方法指引**：
1. 立场偏向：作者有什么预设立场？
2. 方法论局限：研究方法有什么固有局限？
3. 可替代解释：有没有其他解释方式？
4. 多元视角对比：不同学派/立场会怎么看？

### 维度七：现实意义 ⭐

**分析问题**：对理解当下有什么用？

**方法指引**：
1. 政策启示：对政策制定有什么启示？
2. 社会实践：对社会实践有什么指导？
3. 日常关联：与普通人的日常生活有什么关系？
4. 跨情境迁移：能否应用到其他社会/文化背景？

## 执行步骤

```
Step 1: 通读全书，标记核心论点和研究问题
Step 2: 梳理理论框架，识别理论流派和核心概念
Step 3: 还原论证逻辑，评估推理严密性
Step 4: 分析经验材料，评估数据/案例质量
Step 5: 分析表达与修辞（传播/演讲适用）
Step 6: 评估现实意义和跨情境迁移
Step 7: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 学术对话式，像一个同行在和你讨论
- 可用"我们"引导分析

### 示范句式
- "作者的核心论点是……，这一观点挑战了传统的……"
- "从……的理论视角来看，这一现象可以被解释为……"
- "值得注意的是，这一结论在……条件下可能不成立。"

### 禁忌用语
- 不要价值预判（武断地说"这个观点是对的/错的"）
- 不要忽视作者的立场偏向
- 不要把复杂的理论争辩简化为对错判断

## 常见陷阱

1. **价值预判**：武断判断观点对错 → 客观呈现不同立场
2. **忽视立场**：不分析作者的预设立场 → 立场偏向是重要维度
3. **简化争辩**：把复杂的理论争辩简化为对错 → 呈现多元视角
4. **脱离语境**：不分析理论的历史/文化背景 → 学术脉络是重要维度
5. **堆砌术语**：堆砌学术术语而不解释 → 首次出现时解释

---

*社会科学分析的关键是：保持学术中立，呈现多元视角，同时不失去对现实问题的关怀。*
