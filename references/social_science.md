# social_science.md — 社会科学分析框架

> 适用：社会学、政治学、经济学、传播学、演讲修辞等社会科学著作。

---

## 体裁特征与识别信号

### 典型文本特征
- **结构**：问题→理论框架→论证→结论 或 现象→分析→解释→启示
- **语言**：学术性、论证性、多用专业概念和理论框架
- **篇幅**：通常 200-400 页
- **标志词**："研究表明""数据显示""理论框架""方法论""样本""变量"

### 常见子类型
- 社会学（《乡土中国》《乌合之众》）
- 经济学（《国富论》《21世纪资本论》《思考，快与慢》经济部分）
- 政治学（《正义论》《独裁者手册》）
- 传播学（《理解媒介》《娱乐至死》《乌合之众》）
- 演讲修辞（《葛底斯堡演说》《我有一个梦想》合集）
- 人类学（《忧郁的热带》《菊与刀》）

### 易混淆体裁及区分要点
- vs **自然科学**：社会科学研究人类社会，难以完全量化实验
- vs **人文艺术**：社会科学侧重客观分析，人文艺术侧重主观审美
- vs **哲学**：社会科学侧重经验研究，哲学侧重概念思辨

## 科普型 vs 学术型社科区分处理

社会科学著作分为两种子类型，**采用不同的分析框架**：

### 识别信号

| 类型 | 识别信号 | 典型示例 |
|------|---------|---------|
| **科普型社科** | 面向大众、案例丰富、语言生动、少用专业术语 | 《乡土中国》《乌合之众》《娱乐至死》《菊与刀》《思考，快与慢》 |
| **学术型社科** | 面向学者、术语密集、引用文献、方法论说明 | 《正义论》《21世纪资本论》《忧郁的热带》《国富论》 |

### 处理规则

**科普型社科（占大多数）**：
- 核心目标：让读者"看懂社会、改变认知、指导行动"
- 侧重：核心观点大白话、认知刷新点、日常关联、表达评估
- 弱化：理论流派归属、论证方法评估、方法论局限（可提及但不深入分析）

**学术型社科（占少数）**：
- 核心目标：理解理论体系和论证逻辑
- 保留专业分析维度（理论框架、论证逻辑、经验材料）

> ⚠️ **默认按科普型社科处理**，除非明显是学术专著（术语密集、引用文献、方法论说明）。

## 分析维度

> 📌 **核心/扩展区分**：标注 ⭐ 为核心维度（精读必做），其余为扩展维度（深度分析时补充）。
>
> 💡 **默认按科普型社科维度执行**，学术型社科可保留"理论框架""论证逻辑""经验材料"等专业维度。

### 维度一：核心观点大白话 ⭐

**分析问题**：这本书最核心的社会洞察是什么？用大白话说清楚。

**方法指引**：
1. 提取核心观点
2. 每个观点用**一句话大白话**解释
3. 标注原文依据（作者怎么说的）
4. 用生活案例辅助解释

**输出格式**：

```markdown
## 核心观点（大白话版）

### 观点1：[标题]
- 大白话解释：[一句话说清楚]
- 原文依据：[引用原文]
- 生活案例：[用生活中的例子辅助理解]

### 观点2：[标题]
...
```

### 维度二：认知刷新点 ⭐

**分析问题**：这本书如何颠覆或刷新了我们已有的社会认知？

**方法指引**：
1. 找出"反直觉"或"意想不到"的社会洞察
2. 每个发现用"原来我以为……现在知道了……"的格式表达
3. 标注原文依据
4. 评估：这个刷新是"有趣但不重要"还是"改变认知"

**输出格式**：

```markdown
## 认知刷新

### 刷新点1：[标题]
- 原来我以为：[常见误解]
- 现在知道了：[社科洞察]
- 原文依据：[引用原文]
- 重要性：★★★（改变认知/有趣但不重要）
```

### 维度三：日常关联 ⭐

**分析问题**：这些社会洞察，和我的生活有什么关系？

**方法指引**：
1. 这本书能解释哪些社会现象？（职场/社交/消费/教育/家庭）
2. 能指导哪些日常决策？
3. 读完后，我看社会的角度有什么不同？
4. 作者的案例是否贴近生活？

**输出格式**：

```markdown
## 日常关联

### 解释社会现象
- [现象1]：[书中洞察如何解释]
- [现象2]：[书中洞察如何解释]

### 指导日常决策
- [决策场景1]：[书中洞察如何指导]
- [决策场景2]：[书中洞察如何指导]

### 认知升级
[读完后，我对XX的理解从___变成了___]
```

### 维度四：多元视角 ⭐

**分析问题**：不同立场的人会怎么看这个问题？

**方法指引**：
1. 作者的立场和预设立场是什么？
2. 有没有其他解释方式？（不同学派/立场会怎么看）
3. 哪些群体可能不同意？为什么？
4. 用大白话呈现分歧焦点（不深入学术争辩）

**输出格式**：

```markdown
## 多元视角

### 作者立场
[作者的预设立场和背景]

### 不同声音
- [群体/学派A]：[核心观点]
- [群体/学派B]：[核心观点]

### 分歧焦点
[用大白话解释：他们到底在争什么？]
```

### 维度五：理论脉络（扩展）

**分析问题**：这个社会理论是怎么来的？

**方法指引**：
1. 用时间线简述发展脉络（关键节点）
2. 标注关键人物和贡献
3. 用大白话解释理论演变（如有）

**输出格式**：

```markdown
## 理论脉络

### 发展脉络
- [年份] [人物] [贡献（大白话）]
- [年份] [人物] [贡献（大白话）]

### 理论演变
[如有，用大白话解释]
```

### 维度七：社会影响与伦理（扩展）

**分析问题**：这个社会发现对社会有什么影响？

**方法指引**：
1. 社会影响：对社会结构/政策/公众认知的影响
2. 伦理讨论：涉及哪些伦理问题？
3. 风险与挑战：可能带来的负面效应

---

## 执行步骤

```
Step 1: 通读全书，提取核心观点
Step 2: 用大白话解释每个观点
Step 3: 找出认知刷新点，用"原来我以为……现在知道了……"表达
Step 4: 关联社会现象和日常决策场景
Step 5: 简述理论脉络和多元视角（扩展）
Step 6: 整合输出，按模板交付
```

## 语气风格规范

### 称呼方式
- 像一个见多识广的朋友在和你聊天
- 用大白话讲清楚，拒绝"术语轰炸"
- 可以用"我们"拉近与读者的距离

### 示范句式
- "用大白话来说，这本书的核心意思是……"
- "打个比方……"
- "读完这个，我原来以为___，现在知道了___"
- "这个案例很生动/有点抽象，因为……"
- "作者讲得很清楚/这里有点难懂，可能是因为……"

### 禁忌用语
- 不要堆砌学术术语而不解释
- 不要评估"论证方法""方法论局限"等专业概念（除非学术型社科）
- 不要把科普型社科当成学术论文分析
- 不要忽视"这本书好不好读"这个核心问题

## 常见陷阱

1. **术语轰炸**：堆砌学术术语而不解释 → 首次出现时用大白话解释
2. **学术化分析**：用评估学术论文的标准分析科普型社科 → 普通读者关心的是"懂不懂"，不是"论证严不严"
3. **脱离生活**：不与日常关联 → 每个核心观点都要思考"这和我有什么关系"
4. **与我无关**：不联系自身 → 社科的最终价值是启发自己
5. **价值预判**：武断判断"这个观点是对的/错的" → 客观呈现多元视角

---

*社会科学分析的关键是：保持学术中立，呈现多元视角，同时不失去对现实问题的关怀。*

## 补充说明：丰富"对我的启示"维度

在"日常关联"基础上，"对我的启示"应包含：
- **认知改变**：我对XX的理解从___变成了___
- **行为意向**：我接下来会如何与不同立场的人讨论这个话题
- **情感体验**：这本书是否改变了我对某个公共议题的态度

## 补充维度：个人处境映射（核心）

**分析问题**：这些社会洞察，如何解释我的具体处境？

**方法指引**：
1. 我的工作/家庭/社交中，有哪些现象可以用这本书解释？
2. 我身上的问题是个人原因还是结构性原因？
3. 这本书如何帮助我理解自己的处境？

**输出格式**：

```markdown
## 个人处境映射

### 解释我的处境
[我的工作/家庭/社交中，有哪些现象可以用这本书解释？]

### 个人vs结构性
[我身上的问题是个人原因还是结构性原因？]

### 新的理解
[这本书如何帮助我理解自己的处境？]
```
