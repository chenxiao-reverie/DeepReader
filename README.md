# DeepReader / 深读宝 📚

> 万能读书助手 — 帮你吃透、读懂、读好一本书

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 简介

DeepReader 是一个 通用Skill，能根据读物体裁自动切换分析框架，
对15种不同体裁的书籍进行深度阅读分析。

## 支持的体裁

| 体裁 | 说明 |
|------|------|
| 📖 个人成长 | 拆书萃取，理解自我 |
| 🧠 心理 | 核心概念、实证基础、自我觉察 |
| 📕 小说故事 | 人物/剧情/伏笔/世界观 |
| 🎭 诗歌散文 | 意象/韵律/情感/思想 |
| 🎬 戏剧 | 冲突/对白/舞台艺术 |
| 🔬 科学 | 假说/证据/理论框架 |
| 📊 社科 | 命题/理论/论证/现实意义 |
| 🧠 哲学 | 概念/论证/思想实验 |
| 👤 人物传记 | 人生/史料/书信日记 |
| ⛪ 宗教神话 | 信仰/教义/原型象征 |
| 🎨 艺术 | 美学/作品/鉴赏 |
| 💼 商业财经 | 模式/战略/投资 |
| 🎯 技能学习 | 教程/技能阶梯/练习体系 |
| 📚 专业参考 | 法律/医学/论文/百科 |

## 核心特性

- **15体裁覆盖**：从个人成长到专业参考，全面覆盖
- **分层分析**：5分钟速览 / 30分钟精读 / 3小时深度分析
- **核心/扩展区分**：精读只做核心，深度全做
- **通用维度**：读者反应日志、批判性审视、知识迁移、当代回响
- **品牌中立**：无品牌依赖，可自由使用

## 使用方式

### 作为 Claude Code Skill

1. 将本仓库克隆到 `~/.claude/skills/deep-reader/`
2. 在 Claude Code 中输入触发词即可使用

### 触发词

- "分析这本书"
- "帮我读XX"
- "深度解读"
- "榨干一本书"
- "拆书"
- "读书笔记"
- "精读"
- "书评"

## 分析流程

```
Step 1: 接收输入
    ↓
Step 2: 文本预处理（章节切分、元信息提取）
    ↓
Step 3: 意图识别与体裁路由
    ↓
Step 4: 确定分析深度（5分钟/30分钟/3小时）
    ↓
Step 5: 加载体裁专属框架
    ↓
Step 6: 结果整合与交付
    ↓
Step 7: 质量自检
```
